# Syllabus — TI MSP430: Embedded Digital Signal Processing

**Hardware:** MSP-EXP430G2 LaunchPad (MSP430G2553)

## Global requirements
- 3 progressive exercises + 1 independent assignment per module
- Labs with expected results, test procedures, debugging guidance
- Solutions separate from learner-facing files
- Git-friendly project layout with build/flash/test documented

## Modules

1. **Embedded DSP foundations**
2. **Discrete-time signals and systems**
3. **ADC-based signal acquisition**
4. **Fixed-point arithmetic**
5. **Time-domain signal analysis**
6. **DFT and spectral analysis**
7. **Small FFT implementations**
8. **FIR filters**
9. **IIR filters**
10. **Practical embedded DSP algorithms**
11. **Real-time acquisition and processing**
12. **DSP optimization and validation**
13. **Final embedded DSP project**

## Final projects

- Fixed-point FIR filter on live ADC input
- Tone detector with goertzel or DFT bin
- Small-window FFT analyzer
- Low-frequency signal monitor / classifier
