🐍 Python Project Setup — From Zero to Hero

🎯 Goal

  • Understand virtual environments (venv)
  • Install dependencies
  • Understand PYTHONPATH
  • Run a project from README

🧠 Part 1 — Concepts

1. Virtual Environment (venv)

A virtual environment is an isolated Python environment for each project.

python -m venv venv

2. Install Dependencies

pip install -r requirements.txt

3. Editable Install

pip install -e .

4. PYTHONPATH

Tell Python where your code lives.

# Windows
$env:PYTHONPATH="src"

# Mac/Linux
export PYTHONPATH=src

5. CLI

python main.py

🚀 Part 2 — Workflow

Step 1 — Create venv

python -m venv venv

Step 2 — Activate

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate

Step 3 — Upgrade pip

python -m pip install --upgrade pip

Step 4 — Install deps

pip install -r requirements.txt

Step 5 — Install project

pip install -e .

Step 6 — Alternative

$env:PYTHONPATH="src"

Step 7 — Run

python main.py

🧪 Exercises

1. Create venv

python -m venv venv

2. Activate

venv\Scripts\activate

3. Install package

pip install requests

4. Freeze

pip freeze > requirements.txt

5. Project structure

project/
  src/
    my_app/
      main.py

6. Run with PYTHONPATH

$env:PYTHONPATH="src"
python -c "from my_app.main import run; run()"

7. setup.py

from setuptools import setup, find_packages

setup(
 name="my_app",
 version="0.1",
 packages=find_packages(where="src"),
 package_dir={"": "src"},
)

8. Break it

Remove PYTHONPATH and uninstall package. Observe errors.

9. CLI

entry_points={
 'console_scripts': ['myapp=my_app.main:run']
}

10. Full workflow

  1. Create venv
  2. Activate
  3. Install deps
  4. Install project
  5. Run CLI
