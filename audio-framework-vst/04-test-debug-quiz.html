Phase 11 — Debugging methodology

Symptom ↓ Hypothesis ↓ Smallest diagnostic ↓ Result ↓ Updated hypothesis ↓ Fix ↓ Explain root cause

Do not randomly change code. One hypothesis at a time.

Phase 12 — Beginner mistakes

Wrong architecture layer — rewriting GenericProcessor for one plugin.
Symptom: huge diffs, merge hell.
Fix: only add/adjust C module + Plugin.h.

Allocating in Calc — Symptom: glitches under load.
Fix: allocate in Init, free in Free.

Assuming fixed block size / stereo — Symptom: works in one host setting, crashes in another.
Fix: always use BlockLength, NumInputs/NumOutputs.

dB vs linear mix-up — Symptom: “−6 dB” barely quieter or nukes signal.
Fix: convert in SetValue/GetValue; store linear in Specific.

Duplicate PluginCode / stale install — Symptom: wrong plugin opens, or changes never appear.
Fix: unique codes; verify timestamp of installed binary.

Forgetting PT_NO_PARAM terminator behavior — Symptom: UI missing params or scanning forever/garbage.
Fix: out-of-range index clears info and sets PT_NO_PARAM.
