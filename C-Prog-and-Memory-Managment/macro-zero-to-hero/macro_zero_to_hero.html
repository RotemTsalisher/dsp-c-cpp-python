C/C++ Macro Training: Zero to Hero

These are hands-on coding exercises. Type each program yourself, compile it, observe what breaks, and only then reveal the solution. By Exercise 5, you will build the same do { ... } while (0) pattern used by real assertion macros.

Exercise 1 - Run exactly once

Get your hands on do/while

Write a do/while block that prints Hello exactly once and increments counter once. Do not use break.

int main(void)
{
    int counter = 0;

    // YOUR CODE

    printf("counter = %d\n", counter);
    return 0;
}
#include <stdio.h>

int main(void)
{
    int counter = 0;
    do {
        printf("Hello\n");
        counter++;
    } while (0);

    printf("counter = %d\n", counter);
    return 0;
}

The body executes before the condition is tested. Then 0 is false, so there is no second iteration.

Exercise 2 - First multi-statement macro

Create a macro that does two things

Implement PRINT_AND_DOUBLE(x). It must print the current value and then double it. Intentionally use two bare statements. Do not use do/while yet.

#include <stdio.h>

#define PRINT_AND_DOUBLE(x) /* YOUR CODE */

int main(void)
{
    int x = 5;
    PRINT_AND_DOUBLE(x);
    printf("final x = %d\n", x);
    return 0;
}

Target: before = 5, then final x = 10.

#define PRINT_AND_DOUBLE(x) \
    printf("before = %d\n", (x)); \
    (x) *= 2

This works here, but your macro expands into two separate C statements. Keep it exactly like this for Exercise 3.

Exercise 3 - Break the macro

Use it inside an if

Use your Exercise 2 macro below. Compile and run it. Explain why x becomes 10 even though run == 0. Then fix only the macro.

int x = 5;
int run = 0;

if (run)
    PRINT_AND_DOUBLE(x);

printf("x = %d\n", x);

Required final result: x = 5. Do not add braces to the caller's if.

The old macro effectively expands to:

if (run)
    printf("before = %d\n", x);
(x) *= 2;

Only the first statement belongs to the if. Fix it:

#define PRINT_AND_DOUBLE(x)       \
    do {                          \
        printf("before = %d\n", (x)); \
        (x) *= 2;                 \
    } while (0)
Exercise 4 - Why braces are not enough

Survive if/else

Replace the do/while with ordinary braces, then compile this code. Read the compiler error. After that, restore the safe version.

#define PRINT_AND_DOUBLE(x) {     \
    printf("before = %d\n", (x)); \
    (x) *= 2;                     \
}

int x = 5;
int run = 1;

if (run)
    PRINT_AND_DOUBLE(x);
else
    printf("not running\n");

The caller's semicolon produces this:

if (run)
{
    printf("before = %d\n", x);
    x *= 2;
};
else
    printf("not running\n");

The semicolon finishes the if, leaving the else stranded. With do { ... } while (0), that semicolon correctly terminates one normal statement.

Exercise 5 - Hero level

Build a real assertion macro

Write ASSERT_INT_EQ(a,b) from scratch.

  • Evaluate a exactly once.
  • Evaluate b exactly once.
  • Store both in local temporary variables.
  • Print PASS if equal.
  • Print both values if unequal.
  • Work correctly inside if/else.
  • Do not leak temporary variables.
int main(void)
{
    int x = 4;
    int y = 4;

    ASSERT_INT_EQ(x, y);
    ASSERT_INT_EQ(x, 20);

    int i = 3;
    ASSERT_INT_EQ(i++, 3);
    printf("i = %d\n", i); // MUST be 4

    if (x > 0)
        ASSERT_INT_EQ(x, y);
    else
        printf("x is invalid\n");

    return 0;
}
#include <stdio.h>

#define ASSERT_INT_EQ(a, b)                 \
    do {                                    \
        int tmp_a_ = (a);                   \
        int tmp_b_ = (b);                   \
        if (tmp_a_ == tmp_b_) {             \
            printf("PASS\n");               \
        } else {                            \
            printf("FAIL: %d != %d\n",      \
                   tmp_a_, tmp_b_);          \
        }                                   \
    } while (0)

The temporaries prevent repeated evaluation. The block provides local scope. The do/while(0) makes the entire macro behave as one statement.

Final mental model

#define MY_MACRO(...) \
    do {              \
        /* many statements */ \
    } while (0)

Read this as: package all of these statements into one safe macro statement with local scope.
