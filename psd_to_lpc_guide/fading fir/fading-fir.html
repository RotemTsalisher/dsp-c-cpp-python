🎧 FIR Crossfading — From Zero to Hero

1. The Problem

Switching FIR filters abruptly causes clicks due to discontinuities.

y = filter(h1, x); // then suddenly
y = filter(h2, x);

Problem: FIR filters have memory → sudden changes = artifacts.

2. The Core Idea — Crossfade

Instead of switching filters, blend outputs:

y[n] = (1 - alpha[n]) * y1[n] + alpha[n] * y2[n]
  • y1 = output of filter h1
  • y2 = output of filter h2
  • alpha goes smoothly from 0 → 1

3. Fade Curves

Linear

alpha = linspace(0,1,N)

Smooth (recommended)

alpha = (1 - cos(pi*n/N)) / 2

4. MATLAB Example

h1 = fir1(64, 0.2);
h2 = fir1(64, 0.6);

x = randn(1,2000);

y1 = filter(h1,1,x);
y2 = filter(h2,1,x);

Nfade = 500;
alpha = [linspace(0,1,Nfade), ones(1, length(x)-Nfade)];

y = (1-alpha).*y1 + alpha.*y2;

5. Streaming Concept

for each block:
    y1 = filter(h1, x_block)
    y2 = filter(h2, x_block)

    y = (1-alpha)*y1 + alpha*y2

Keep filter states and update alpha gradually.

6. Pitfalls

  • Too fast fade → clicks
  • Too slow → double filtering sound
  • Different filter lengths → must align
  • Phase mismatch → smearing

🧪 Exercises (With Solutions)

Exercise 1 — Basic FIR

Create a lowpass filter and apply it to noise.

h = fir1(64, 0.3);
x = randn(1,1000);
y = filter(h,1,x);
plot(y);

Exercise 2 — Two Filters

Create lowpass and highpass filters.

h1 = fir1(64, 0.3);
h2 = fir1(64, 0.3, 'high');

x = randn(1,1000);
y1 = filter(h1,1,x);
y2 = filter(h2,1,x);

Exercise 3 — Hard Switch

Switch filters abruptly and observe artifacts.

y = [y1(1:500), y2(501:end)];

Exercise 4 — Linear Crossfade

alpha = linspace(0,1,length(x));
y = (1-alpha).*y1 + alpha.*y2;

Exercise 5 — Smooth Fade

n = 0:length(x)-1;
alpha = (1 - cos(pi*n/length(x))) / 2;
y = (1-alpha).*y1 + alpha.*y2;

Exercise 6 — Block Processing

blockSize = 128;
state1 = zeros(64,1);
state2 = zeros(64,1);

for i=1:blockSize:length(x)
    block = x(i:i+blockSize-1);

    [y1,state1] = filter(h1,1,block,state1);
    [y2,state2] = filter(h2,1,block,state2);

    y_block = 0.5*y1 + 0.5*y2;
end

Exercise 7 — Full System

Build a real-time style crossfading system.

alpha = 0;
alpha_step = 0.001;

for n=1:length(x)
    y1 = filter(h1,1,x(n));
    y2 = filter(h2,1,x(n));

    y(n) = (1-alpha)*y1 + alpha*y2;
    alpha = min(alpha + alpha_step,1);
end

🚀 Final Advice

  • Always listen, not just plot
  • Test extreme transitions
  • Use cosine fades for best results
  • Think in terms of signal continuity
