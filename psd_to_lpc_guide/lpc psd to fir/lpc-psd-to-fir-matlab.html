PSD → LPC → FIR Crossfading (Zero → Hero)

1. The Big Picture

We want to transform a signal into a spectral model and smoothly morph it: 

Signal → PSD → Autocorrelation → LPC → FIR → Crossfade → Output

This pipeline is used in speech coding, audio effects, and adaptive filtering.

2. Power Spectral Density (PSD)

The PSD describes how signal power is distributed across frequency: 

Sx(ω) = |X(e^{jω})|²

In MATLAB: 

[Pxx, f] = pwelch(x, [], [], N, fs);

This gives a smooth estimate of the signal spectrum.

3. PSD → Autocorrelation (Critical Step)

The PSD and autocorrelation are Fourier transform pairs: 

r[k] = (1 / 2π) ∫ Sx(ω) e^{jωk} dω

This means:

If you know the PSD, you can recover the autocorrelation.

In MATLAB:

r = real(ifft(Pxx));

This step is the bridge between frequency domain and time-domain modeling.

4. LPC Model

We model the signal as predictable from past samples: 

x[n] + Σ (k=1→p) a_k x[n-k] = e[n]

Where:

  • e[n] = white noise (prediction error)
  • a_k = LPC coefficients

5. Deriving Yule-Walker Equations

We minimize prediction error: 

E[e[n]²] minimized

Using orthogonality: 

E[e[n] x[n-m]] = 0

Substitute the model: 

r[m] + Σ a_k r[m-k] = 0

This gives a linear system:

R * a = -r

Where R is a Toeplitz matrix: 

[r0 r1 r2 ...]
[r1 r0 r1 ...]
...

6. What LPC is Actually Doing

LPC approximates the PSD using an all-pole model: 

Sx(ω) ≈ σ² / |1 + Σ a_k e^{-jωk}|²

👉 Peaks in PSD → poles in filter 👉 LPC captures spectral envelope (not fine detail)

7. MATLAB: Full PSD → LPC (Manual)

x = randn(1,1024);
p = 16;

[Pxx,~] = pwelch(x, [], [], 1024);
r = real(ifft(Pxx));

R = toeplitz(r(1:p));
rhs = -r(2:p+1);

a = R \ rhs;
a = [1; a];

8. LPC → FIR Conversion

LPC is IIR (all-pole). For real-time crossfading we convert to FIR: 

imp = [1 zeros(1,255)];
h = filter(1, a, imp);

9. Crossfading FIR Filters

We smoothly interpolate: 

h_interp = (1 - α)h1 + αh2

This avoids clicks and ensures stability.

Exercise 7 — FINAL: Crossfade System

Build full system: LPC → FIR → smooth crossfade. 

x1 = randn(1,1024);
x2 = filter([1 0.5],1,x1);

p = 16;

a1 = lpc(x1,p);
a2 = lpc(x2,p);

imp = [1 zeros(1,255)];

h1 = filter(1,a1,imp);
h2 = filter(1,a2,imp);

alpha = linspace(0,1,512);
y = zeros(1,512);

for n=1:512
    h_interp = (1-alpha(n))*h1 + alpha(n)*h2;
    y(n) = filter(h_interp,1,x1(n));
end

plot(y);

Final Insight

You are fitting a spectral model (LPC) to a PSD, converting it into a stable FIR, and morphing between spectral envelopes in real time.
