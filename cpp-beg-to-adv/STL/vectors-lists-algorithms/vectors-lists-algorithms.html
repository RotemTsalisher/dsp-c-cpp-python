What is STL?

STL = Standard Template Library. It gives ready-made containers and algorithms so you don’t need to reinvent data structures.

  • Containers: vector, list, map, set...
  • Algorithms: sort, find, count...
  • Iterators: objects used to move through containers

Learning STL makes your C++ code shorter, cleaner, faster, and more professional.

PART 1 — VECTOR MASTERCLASS

Theory

A vector is a dynamic array. It stores items in continuous memory like arrays, but can resize automatically.

Best for:

  • Fast indexing
  • Appending values
  • General-purpose storage
#include <vector>
using namespace std;

Methods (Every Method with Examples)

push_back(x)

Add item to end.

vector<int> v;
v.push_back(5);
v.push_back(9);
// {5,9}

pop_back()

Remove last item.

vector<int> v = {1,2,3};
v.pop_back();
// {1,2}

size()

Returns number of elements.

vector<int> v = {7,8,9};
cout << v.size(); // 3

empty()

Checks if vector has no items.

vector<int> v;
cout << v.empty(); // 1 (true)

front() / back()

vector<int> v = {10,20,30};
cout << v.front(); // 10
cout << v.back();  // 30

[] and at()

at() gives bounds checking.

vector<int> v = {4,5,6};

cout << v[1];    // 5
cout << v.at(2); // 6

insert()

Insert before position.

vector<int> v = {1,3};
v.insert(v.begin()+1, 2);
// {1,2,3}

erase()

Erase one element.

vector<int> v = {1,2,3};
v.erase(v.begin()+1);
// {1,3}

clear()

vector<int> v = {1,2};
v.clear();
// {}

Create empty vector. Add 10,20,30 and print.
Solution

Solution

3. Sum values

Solution

Solution

6. Insert 99 in middle

7. Reverse print manually

Solution 
for(int i=v.size()-1;i>=0;i--)
    cout << v[i] << " ";

PART 2 — LIST MASTERCLASS

Theory

A list is a doubly linked list. Each item knows previous and next item.

Best for:

  • Frequent insertion/removal
  • Unknown size changing often

Not good for:

  • Indexing like list[5]
#include <list>

Methods

push_front(x)

list<int> l;
l.push_front(5);

push_back(x)

l.push_back(10);

pop_front()

l.pop_front();

pop_back()

l.pop_back();

remove(value)

list<int> l = {1,2,2,3};
l.remove(2);
// {1,3}

sort()

list<int> l = {4,1,3};
l.sort();

reverse()

l.reverse();

7 Exercises

1. Build and print list

Solution 
list<int> l = {1,2,3};
for(int x:l) cout<<x<<" ";

2. Add urgent item at front

Solution 
l.push_front(99);

3. Remove last

Solution 
l.pop_back();

4. Sort numbers

Solution 
l.sort();

5. Reverse list

Solution 
l.reverse();

6. Remove all 7

Solution 
l.remove(7);

7. Count manually

Solution 
int c=0;
for(int x:l) c++;

PART 3 — ALGORITHMS MASTERCLASS

Theory

Algorithms work with iterators. They make code elegant and reusable. 

#include <algorithm>

Methods

sort()

sort(v.begin(), v.end());

sort descending

sort(v.begin(), v.end(), greater<int>());

find()

auto it = find(v.begin(), v.end(), 8);

count()

int c = count(v.begin(), v.end(), 5);

reverse()

reverse(v.begin(), v.end());

max_element()

cout << *max_element(v.begin(), v.end());

min_element()

cout << *min_element(v.begin(), v.end());

7 Exercises

1. Sort ascending

Solution
sort(v.begin(), v.end());

2. Sort descending

Solution
sort(v.begin(), v.end(), greater<int>());

3. Find number 10

Solution
find(v.begin(), v.end(), 10);

4. Count 7s

Solution
count(v.begin(), v.end(), 7);

5. Reverse values

Solution
reverse(v.begin(), v.end());

6. Largest item

Solution
*max_element(v.begin(), v.end());

7. Smallest item

Solution
*min_element(v.begin(), v.end());
