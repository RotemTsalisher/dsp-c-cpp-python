Introduction

Associative containers store data as key-value pairs. Instead of indexing by position like vectors, you access values using keys.

Example: 

map<string,int> age;

age["David"] = 31;
age["Sarah"] = 27;

Here:

  • "David" is the key
  • 31 is the value

Maps are extremely useful for:

  • Dictionaries
  • Frequency counters
  • ID lookups
  • Settings storage
  • Fast searching by key

PART 2 — Insertion and Updating

Subscript Operator []

Use [] to insert or update values in map. 

map<string,int> m;

m["A"] = 5;   // insert
m["A"] = 9;   // update

insert()

Insert a key-value pair. If key already exists in standard map, insertion is ignored. 

map<int,string> m;

m.insert(make_pair(1,"One"));
m.insert(make_pair(1,"Again")); // ignored

Iteration with Iterators

map<string,int> m;

m["A"] = 10;
m["B"] = 20;

for(auto it = m.begin(); it != m.end(); ++it)
{
    cout << it->first  << " ";
    cout << it->second << endl;
}

PART 3 — Internal Structures

map uses Red-Black Tree

  • Automatically sorted by key
  • Search / insert typically O(log n)
map<int,string> m;

m[5]="A";
m[1]="B";
m[9]="C";

Output order when iterating: 

1 B
5 A
9 C

unordered_map uses Hash Table

  • No sorted order
  • Average O(1) access
  • Usually faster lookups
unordered_map<int,string> u;

PART 4 — Multi Containers

multimap

Allows multiple values for same key. 

multimap<string,int> mm;

mm.insert(make_pair("Math",90));
mm.insert(make_pair("Math",95));

unordered_multimap

Same idea, but hash-based and unordered.

No [] Operator in multimap

Because many entries may share the same key, C++ cannot know which one to update.

Exercises

8. Duplicate Keys in multimap

multimap<string,int> mm;

mm.insert(make_pair("A",20));

9. Iterate multimap
