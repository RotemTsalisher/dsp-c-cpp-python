DAFX-inspired Project Roadmap

Each project includes 3 implementation stages:

  • 🔧 Proof of Concept (MATLAB or Pure Data)
  • 💿 VST Plugin (for PC)
  • ⚙️ Embedded Target (e.g., ARM Cortex-M, Bela, Raspberry Pi)

1) Frequency Modulation Reverb

Extend classical reverberation with FM modulation for evolving decay character (inspired by modulation effects + reverberation chapters).

Proof of Concept
  • Implement Schroeder reverberator in MATLAB.
  • Add an LFO-controlled FM segment to one of the comb filters.
  • Visualize frequency response and decay envelope.
VST Plugin
  • Use JUCE to wrap algorithm into a cross-platform VST3.
  • Add GUI sliders for FM depth/rate + reverb time/damping.
  • Test in DAWs like Reaper and Ableton.
Embedded Target
  • Port optimized C++ to an ARM Cortex-M4 (FPU) board.
  • Use DMA audio + I2S codec (e.g., on a Teensy Audio Shield).
  • Physical knobs for depth/rate/time controls.

2) Real-Time Pitch Shifting with Granular Synthesis

Create a pitch shifter based on overlapping granules and windowing.

Proof of Concept
  • Write granular pitch shifter in MATLAB (buffer + Hanning windows).
  • Test on sine sweeps and real audio.
  • Plot time-frequency representation.
VST Plugin
  • Implement real-time circular buffer with grain scheduler in JUCE.
  • Expose parameters: grain size, overlap, pitch factor.
  • Include CPU usage meter and oversampling.
Embedded Target
  • Run granular engine on Raspberry Pi with ALSA or PortAudio.
  • UI via small touchscreen or rotary encoders.
  • Optimize with NEON/FFT SIMD.

3) Wave-Digital Filter Bank Synthesizer

Use wave-digital filters to create a multi-band resonator synth.

Proof of Concept
  • Implement scattering junctions for filters in MATLAB.
  • Create a bank of tuned resonators.
  • Explore stability with different terminations.
VST Plugin
  • Wrap filter bank engine in a JUCE synth plugin (VST3/AU).
  • Add envelopes / LFO control.
  • Preset manager for timbre variations.
Embedded Target
  • Bela or Teensy 4 with audio shield.
  • Physical keyboard or MIDI input.
  • Realtime UI for filter tuning.

4) Adaptive Noise Reduction (Spectral Subtraction)

Design and implement a spectral noise reducer with adaptive noise estimation.

Proof of Concept
  • Implement STFT / ISTFT in MATLAB.
  • Compute noise estimate and subtract spectrum.
  • Evaluate on noisy speech.
VST Plugin
  • Optimized FFT implementation in real time.
  • Controls for attack/release and floor.
  • Plot spectral estimate in GUI.
Embedded Target
  • DSP board with high memory (e.g., ADAU1452 or ARM Cortex-A).
  • Real-time FFT library (KissFFT / CMSIS-DSP).
  • Footswitch bypass + LED status.

5) Binaural Spatializer with HRTF Interpolation

Implement spatial audio using HRTF datasets with smooth interpolation between directions.

Proof of Concept
  • Load HRTF dataset in MATLAB.
  • Implement interpolation on sphere (slerp / VBAP).
  • Test with headphone convolution.
VST Plugin
  • Create real-time convolution engine in JUCE using FFT convolution.
  • Control azimuth/elevation UI.
  • Use presets for common listening scenarios.
Embedded Target
  • Raspberry Pi + USB audio + headphone jack.
  • Efficient FFT convolution (overlap-save).
  • Physical joystick to control spatial position.
