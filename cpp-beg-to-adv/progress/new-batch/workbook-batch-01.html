Exercise 1Functions

Task: Implement int clampInt(int value, int lo, int hi) that returns value limited to [lo, hi]. If lo > hi, return value unchanged (note that in a one-line comment).

// If lo > hi, range is invalid — return value unchanged.

int clampInt(int value, int lo, int hi) {

    if (lo > hi) return value;

    if (value < lo) return lo;

    if (value > hi) return hi;

    return value;

}

Exercise 2Overloading

Task: Overload pickLarger three times: for two int, return the greater int; for two double, return the greater double; for two const char*, return the pointer to the lexicographically larger C string (use a simple loop comparing unsigned char until a difference or '\0'; if one string is a prefix of the other, the longer one wins). No std::string.

int pickLarger(int a, int b) { return (a > b) ? a : b; }



double pickLarger(double a, double b) { return (a > b) ? a : b; }



const char* pickLarger(const char* a, const char* b) {

    if (!a) return b;

    if (!b) return a;

    for (;; ++a, ++b) {

        unsigned char ca = static_cast<unsigned char>(*a);

        unsigned char cb = static_cast<unsigned char>(*b);

        if (ca != cb) return (ca > cb) ? a : b;

        if (ca == '\0') return a; // both ended — strings equal

    }

}

Exercise 5Lambda functions

Task: Use a C array: int data[] = {1,2,3,4,5};. Write a lambda that captures int& sum by reference and takes one int parameter, adding it to sum. Loop with an index or pointer from data to data + 5, calling the lambda each time. After the loop, sum must be 15. No standard containers or algorithms.

int main() {

    int data[] = {1, 2, 3, 4, 5};

    int sum = 0;

    auto acc = [&sum](int x) { sum += x; };

    for (int i = 0; i < 5; ++i)

        acc(data[i]);

    return sum == 15 ? 0 : 1;

}

Exercise 6requires

Task: Using only language + list topics: define variable templates is_fp_v<T> (default false, true for float and double via full specializations—this is template specialization / traits style from the list). Then write template<typename T> T safeDivide(T a, T b) with a requires clause so it exists only when is_fp_v<T> is true. Calling with int must not compile.

template <typename T>

constexpr bool is_fp_v = false;



template <>

constexpr bool is_fp_v<float> = true;



template <>

constexpr bool is_fp_v<double> = true;



template <typename T>

requires (is_fp_v<T>)

T safeDivide(T a, T b) {

    return a / b;

}

Exercise 7Function pointers

Task: using IntBinOp = int (*)(int, int);. Implement add and mul. Write int apply(IntBinOp op, int x, int y). Store add and mul in a C array of two function pointers, loop with indices 0 and 1, and combine results (e.g. return apply(ops[0],3,4) + apply(ops[1],3,4) from main and check it equals 19). No std::array or std::function.

int add(int a, int b) { return a + b; }

int mul(int a, int b) { return a * b; }



using IntBinOp = int (*)(int, int);



int apply(IntBinOp op, int x, int y) {

    return op(x, y);

}



int main() {

    IntBinOp ops[2] = {add, mul};

    int a = apply(ops[0], 3, 4);

    int b = apply(ops[1], 3, 4);

    return (a + b == 19) ? 0 : 1;

}
