Exercise 1Passing functions

Task: Write template<typename F> void invokeTwice(F f) that calls f() twice (pass lambda by value so no std::forward / <utility>). In main, use a lambda that increments an outer int n captured by reference; after invokeTwice, n == 2.

template <typename F>
void invokeTwice(F f) {
    f();
    f();
}

int main() {
    int n = 0;
    invokeTwice([&n] { ++n; });
    return n == 2 ? 0 : 1;
}

Exercise 4Traits

Task: Without std::true_type: primary template<typename T> struct IsPointer { static constexpr bool value = false; }; partial specialization for T* with value = true. Variable template is_pointer_v<T> aliasing IsPointer<T>::value. static_assert for int* and int.

template <typename T>
struct IsPointer {
    static constexpr bool value = false;
};

template <typename T>
struct IsPointer<T*> {
    static constexpr bool value = true;
};

template <typename T>
constexpr bool is_pointer_v = IsPointer<T>::value;

static_assert(is_pointer_v<int*>);
static_assert(!is_pointer_v<int>);

Exercise 5Threads

Task: Two std::thread objects. Each runs a plain function (not required to be a lambda) that takes int* and writes the sum 1+2+3+4+5 into *out for distinct ints s1 and s2 in main. join both. Return s1 == 15 && s2 == 15 ? 0 : 1. No mutex (no shared mutable state between threads).

#include <thread>

void sumFive(int* out) {
    *out = 1 + 2 + 3 + 4 + 5;
}

int main() {
    int s1 = 0, s2 = 0;
    std::thread t1(sumFive, &s1);
    std::thread t2(sumFive, &s2);
    t1.join();
    t2.join();
    return (s1 == 15 && s2 == 15) ? 0 : 1;
}

Exercise 7Concepts

Task: Define is_int_v / is_double_v as variable templates with full specializations (only int and double true). Concept Numeric true when either holds. template<Numeric T> T add(T a, T b). Verify mentally that add(1,2) works and a third type does not. No std::string, no std::disjunction.

template <typename>
constexpr bool is_int_v = false;
template <>
constexpr bool is_int_v<int> = true;

template <typename>
constexpr bool is_double_v = false;
template <>
constexpr bool is_double_v<double> = true;

template <typename T>
concept Numeric = is_int_v<T> || is_double_v<T>;

template <Numeric T>
T add(T a, T b) {
    return a + b;
}
