Const Correctness Quiz (20 Questions)

📘 Introduction: Const Correctness & Const Placement (From Basics → Expert)

Const correctness is one of the most important ideas in C++. It helps you write safer, clearer, and more predictable code. At its core, const means: "this thing cannot be modified" — but where you place const changes what exactly is protected.

1️⃣ Const with Variables

const int x = 5;  // x cannot be changed

This is the simplest case: a constant value.

2️⃣ Const with Pointers (VERY IMPORTANT)

Const can apply to the data or to the pointer itself.

const int* p;     // pointer to const int (data is const)
int* const p;     // const pointer to int (pointer is const)
const int* const p; // both are const

Golden Rule (read right-to-left):

  • int const* p → p is pointer to const int
  • int* const p → p is const pointer to int

Examples:

int x = 5;
int y = 10;

const int* p1 = &x; // cannot modify *p1
p1 = &y;            // OK

int* const p2 = &x; // cannot change pointer
*p2 = 20;           // OK

const int* const p3 = &x; // nothing can change

3️⃣ Const with References

const int& ref = x; // reference to const

You cannot modify x through ref.

4️⃣ Const with Functions (Return Type)

const int get();

This means the returned value is const (rarely useful in practice).

5️⃣ Const Member Functions (OOP 🔥)

class Car {
public:
    int speed;
    int getSpeed() const {
        return speed;
    }
};

The const at the end means: this function will NOT modify the object.

Inside such functions:

  • You cannot modify member variables
  • You can only call other const functions

6️⃣ Why This Matters

  • Prevents bugs (compiler enforces rules)
  • Improves readability (clear intent)
  • Allows usage with const objects

7️⃣ Advanced Insight

Const correctness scales with system size. In large systems (DSP, embedded, real-time), const helps ensure components don't accidentally modify shared data.

👉 Think of const as a contract: once you promise not to change something, C++ will enforce that promise for you.

🧠 Final Mental Model

  • Left of * → data is const
  • Right of * → pointer is const
  • After function () → object is const

Example summary:

const int* p;      // data const
int* const p;      // pointer const
const int* const p; // both const
int foo() const;   // object const
