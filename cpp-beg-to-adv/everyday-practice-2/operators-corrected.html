Operator Overloading Practice

1. Vector2D + Vector2D

Create a class Vector2D containing x and y. Implement: 

Vector2D a(1,2);
Vector2D b(3,4);

Vector2D c = a + b;

Decide:

  • Should operator+ be member or non-member?
  • What should it return?
  • Should parameters be const?
Typical solution: operator+ returns a new object. Arguments should be const. Either member or free function is acceptable.

2. Left and Right Scalar Multiplication

Support BOTH: 

Vector2D v(1,2);

v * 5;
5 * v;

Which operator must be a free function and why?

A member operator can only handle: v * 5 because the left operand is Vector2D. To support: 5 * v you need a non-member operator.

3. Complex Number Arithmetic

Create a Complex class. Support: 

a + b
a - b
a * b

Make expressions like: 

a + b + c

work correctly.

Return objects by value. Avoid returning references to temporary objects.

4. += versus +

Implement: 

v += other;

Then implement: 

v + other;

using += internally.

Common pattern: operator+= modifies current object. operator+ creates a copy and applies +=.

5. Equality Operators

Implement: 

a == b
a != b

Avoid duplicate logic.

Implement operator== once. Implement operator!= using !(a==b).

6. Stream Operators

Implement: 

std::cout << point;
std::cin >> point;

Why can these operators NOT be member functions of Point?

Left operand is ostream/istream. Therefore Point cannot be the owner of the operator.

7. Inheritance + Operator Overloading

Given: 

class Shape
class Circle : public Shape

Implement: 

circle1 == circle2

using data inherited from Shape and data inside Circle.

Think about:

  • access to protected members
  • slicing
  • const correctness
Operator should compare both base and derived state. Often call a base comparison helper.

8. The Symmetry Trap

Design a Temperature class.

Support ALL: 

Temperature t(20);

t + 5;
5 + t;

t - 5;
5 - t;

Without duplicating code.

Excellent exercise for understanding member vs non-member operators, conversion rules, and code reuse.
