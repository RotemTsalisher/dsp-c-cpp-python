AFE-ENTRY-101P0 · BlockerSoak + ASan

Crash on teardown deleting encoder through IEncoder*

Problem

Host deletes a NotchEncoder through IEncoder*. Under ASan the delete is undefined behaviour and may crash during long-run soak.

Fix (bug is here)

include/afe/iencoder.hpp — IEncoder destructor and NotchEncoder teardown path.

Reproduce

.\build\Debug\afe_ticket_test.exe AFE-ENTRY-101
observed has_virtual_destructor_v<IEncoder>: 0
expected has_virtual_destructor_v<IEncoder>: 1
Pass criteria: AFE-ENTRY-101 PASS and exit code 0.
Hint: Polymorphic bases deleted through a pointer need a virtual destructor.

Root cause: Non-virtual destructor on a polymorphic interface.

struct IEncoder {
    virtual void encode_frame(double const* frame, int count) = 0;
    virtual ~IEncoder() = default;
};
