AFE-STAFF-301P0 · BlockerOverflow audit

Signed add wraps at INT_MAX

Problem

safe_add_i32(INT_MAX, 1) wraps to INT_MIN. Certification requires a sentinel -1 on overflow instead of undefined wrapping.

Fix (bug is here)

src/safe_add.cpp — safe_add_i32.

Reproduce

.\build\Debug\afe_ticket_test.exe AFE-STAFF-301
observed safe_add_i32(INT_MAX, 1): -2147483648
expected safe_add_i32(INT_MAX, 1): -1
Pass criteria: AFE-STAFF-301 PASS
Hint: Detect positive overflow before performing raw signed addition.
if (b > 0 && a > INT_MAX - b) return -1;
return a + b;
