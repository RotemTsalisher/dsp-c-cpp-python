VLC-JR-203P2 · MajorPlugin SDK

NotchSource silent through Source*

Problem

Plugin host stores NotchSource as Source* and calls next(). Without virtual, static binding always runs the base implementation (silence).

Fix (bug is here)

include/vlc/source.hpp — declare virtual double next(). include/vlc/notch_source.hpp — mark override.

Reproduce

.\build\Debug\vlc_ticket_test.exe VLC-JR-203
observed Source* -> NotchSource::next(): 0
expected dynamic dispatch into NotchSource: > 0
Pass criteria: VLC-JR-203 PASS
Hint: Extension points called through base pointers must be virtual.
class Source {
public:
    virtual double next() { return 0.0; }
    ...
};
class NotchSource : public Source {
    double next() override;
};
