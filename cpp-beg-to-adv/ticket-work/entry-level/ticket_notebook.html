System under maintenance — VoiceLink Core (VLC)

What it is: Embedded voice uplink path for a duplex intercom product. 48 kHz PCM in, optional stereo-to-mono mix before narrowband wind PSD, software trims on an AFE register block, and a small HeapBins-style scratch buffer for PSD bins.

Your role (entry): QA files straightforward defects—wrong constants, obvious leaks, missing returns on chained configurators, and arithmetic slip-ups in scaling helpers. You read the ticket, reproduce mentally from the snippet, patch the C++, and explain the fix in the review comment.

Reference codebase: the buildable VLC tree lives in ../vlc-core-system/ (include/vlc/, src/, CMakeLists.txt). Open the matching headers and sources while working each ticket.

VLC-ENTRY-101 P3 · Minor Opened by QA · Field soak

Mono mix sounds 6 dB hot on uplink

Summary: Uplink mono downmix from L/R appears louder than lab reference when both channels carry the same tone. Steps: (1) Play 1 kHz −20 dBFS identical on L and R. (2) Enable uplink mono mix. (3) Measure uplink level. Expected: Same RMS as single-channel reference within 0.2 dB. Actual: ~+6 dB vs reference. Component: monoMixDown() in uplink_mix.cpp.

Hint: When L and R are equal, what coefficient on (L+R) keeps energy invariant?

Root cause: Summing L+R without halving doubles amplitude for correlated signals.

double monoMixDown(double const left, double const right)
{
    return 0.5 * (left + right);
}

Review note: Plain functions / simple arithmetic—coefficient must be 0.5 for energy-preserving mono mix of floating PCM.

VLC-ENTRY-102 P3 · Minor Opened by QA · Bench

ADC full-scale mapping reads 2× high

Summary: Calibrated voltage readout from 12-bit ADC counts is systematically ~2× high vs DMM on DC input. Steps: Apply 1.25 V known DC, read driver output. Expected: 1.25 V ± tolerance. Actual: ~2.5 V. Component: countsToVolts()

Hint: Check the denominator: is it 2^bits or 2^bits - 1 for a unipolar ADC spanning 0…full scale?

Root cause: Used 1 << bits as scale; last code is 2^bits - 1.

#include <cmath>

double countsToVolts(double const counts, double const fullScaleVolts, int const bits)
{
    double const denom = std::ldexp(1.0, bits) - 1.0;
    return (counts / denom) * fullScaleVolts;
}

Review note: constexpr-friendly pattern often uses ldexp for the denominator; this is a classic off-by-one-scale bug in functions.

VLC-ENTRY-103 P2 · Major Opened by QA · Long-run soak

PSD soak test leaks memory (heap growth)

Summary: Overnight PSD logging soak shows slow RSS climb on host HIL; embedded counterpart shows allocator failures after ~6 h. Steps: Cycle wind PSD capture 1e6 times with fixed bin count. Expected: Stable heap. Actual: Linear growth. Component: class HeapBins (constructor allocates; suspect destructor).

Hint: Every new[] needs a matching cleanup in the object lifetime end.

Root cause: Destructor empty or missing delete[].

#include <cstddef>

class HeapBins
{
public:
    explicit HeapBins(std::size_t const n) : bins_{new double[n]{}} {}
    ~HeapBins() { delete[] bins_; }
    HeapBins(HeapBins const&) = delete;
    HeapBins& operator=(HeapBins const&) = delete;
    double* data() { return bins_; }
private:
    double* bins_{};
};

Review note: Classes: Destructors + managing class objects through pointers hygiene—RAII lesson before smart pointers enter the curriculum.

VLC-ENTRY-104 P3 · Minor Opened by QA · UI automation

Fluent mic gain API no longer chains

Summary: Factory test calls g.setDb(-6).setDb(-3) but second call does not apply; only first sticks. Steps: See attached one-liner repro. Expected: Final gain matches last setDb. Actual: Intermediate value frozen. Component: MicGainChain

Hint: Fluent setters must return a reference to the same object.

Root cause: setDb returned void or a temporary copy instead of *this.

#include <cmath>

class MicGainChain
{
public:
    MicGainChain& setDb(double const db)
    {
        linear_ = std::pow(10.0, db / 20.0);
        return *this;
    }
    double linear() const { return linear_; }
private:
    double linear_{1.0};
};

Review note: this pointer / chaining class functions—return type must be MicGainChain&.

VLC-ENTRY-105 P2 · Major Opened by QA · Regression

Wind PSD bin #0 always zero after “const cleanup”

Summary: After a const-correctness refactor, DC bin of PSD never updates; higher bins OK. Steps: White noise input, dump bin 0 vs bin 4. Expected: Bin 0 tracks low-frequency energy. Actual: Bin 0 stuck at 0. Component: WindPsdScratch::writeBin(int i, double v) marked const by mistake.

Hint: Mutating member state is not allowed on a const member function.

Root cause: writeBin incorrectly declared const while writing bins_[i].

#include <cstddef>

class WindPsdScratch
{
public:
    void writeBin(int const i, double const v)
    {
        bins_[static_cast<std::size_t>(i)] = v;
    }
    double readBin(int const i) const
    {
        return bins_[static_cast<std::size_t>(i)];
    }
private:
    double bins_[64]{};
};

Review note: Classes: const correctness—writers are non-const; readers stay const.
