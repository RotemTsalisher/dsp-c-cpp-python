VLC-SR-301P0 · BlockerSoak + ASan

Crash on teardown deleting codec through ICodec*

Problem

Host deletes a derived codec through ICodec*. Without a virtual destructor, the delete is undefined behavior and ASan reports invalid free.

Fix (bug is here)

include/vlc/icodec.hpp — ICodec::~ICodec must be virtual.

Reproduce

.\build\Debug\vlc_ticket_test.exe VLC-SR-301
observed has_virtual_destructor_v<ICodec>: 0
expected has_virtual_destructor_v<ICodec>: 1
Pass criteria: VLC-SR-301 PASS
Hint: Any polymorphic base deleted through a pointer needs virtual ~Base().
struct ICodec {
    virtual void encode_frame(...) = 0;
    virtual ~ICodec() = default;
};
VLC-SR-302P1 · CriticalCertification

FancyBox route id lost in telemetry

Problem

route_box_by_value takes Box by value, slicing a FancyBox to its base subobject. Logs show id 1 instead of 2.

Fix (bug is here)

include/vlc/box_telemetry.hpp — route_box_by_value parameter type (or make id() virtual and pass by reference/pointer).

Reproduce

.\build\Debug\vlc_ticket_test.exe VLC-SR-302
observed FancyBox.id(): 2
observed route_box_by_value(FancyBox): 1
expected route_box_by_value(FancyBox): 2
Pass criteria: VLC-SR-302 PASS
Hint: Value parameters slice derived objects unless the API uses references/pointers or virtual functions.
inline int route_box_by_value(FancyBox const& box) {
    return box.id();
}
VLC-SR-303P1 · CriticalGolden FFT

LabCurve eval wrong through ICurve*

Problem

The one-argument LabCurve::eval delegates with norm=true, doubling the sample when called through ICurve const*.

Fix (bug is here)

src/lab_curve.cpp — LabCurve::eval(double) should delegate with norm=false.

Reproduce

.\build\Debug\vlc_ticket_test.exe VLC-SR-303
observed ICurve::eval(0.5): 1
expected ICurve::eval(0.5): 0.5
Pass criteria: VLC-SR-303 PASS
Hint: Default arguments are not virtual; the one-arg override must pick the correct explicit overload.
double LabCurve::eval(double const x) const {
    return eval(x, false);
}
