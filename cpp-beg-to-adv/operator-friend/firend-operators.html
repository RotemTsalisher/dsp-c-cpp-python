Friend Operators in C++ — Complete Guide

1. What is a "friend" function?

A friend function is a function that is NOT a member of a class, but has access to its private and protected members. 

class Vec2 {
private:
    double x, y;

public:
    friend void printVec(const Vec2& v);
};
---

2. Why use friend operators?

  • To allow access to private data
  • To implement operators where the left operand is NOT your class
  • To enable symmetric operations (e.g., int + Vec2)
---

3. Member vs Friend Operator

Member

v + 3   → v.operator+(3)

Friend (Non-member)

3 + v   → operator+(3, v)
---

4. Canonical Pattern

Step 1: Member operator

class Vec2 {
public:
    double x, y;

    Vec2 operator+(int t) const {
        return {x + t, y + t};
    }
};

Step 2: Friend for symmetry

class Vec2 {
public:
    double x, y;

    friend Vec2 operator+(int t, const Vec2& v) {
        return v + t;
    }
};
---

5. When MUST you use friend?

  • Left operand is not your class
  • You need access to private members
  • You want symmetric operator behavior
---

6. Common Use Cases

✔ Arithmetic symmetry

Vec2 operator+(int t, const Vec2& v);

✔ Stream operators

friend std::ostream& operator<<(std::ostream& os, const Vec2& v);

✔ Comparison operators

friend bool operator==(const Vec2& a, const Vec2& b);
---

7. Example: Full Implementation

#include <iostream>

class Vec2 {
private:
    double x, y;

public:
    Vec2(double x, double y) : x(x), y(y) {}

    Vec2 operator+(int t) const {
        return {x + t, y + t};
    }

    friend Vec2 operator+(int t, const Vec2& v) {
        return v + t;
    }

    friend std::ostream& operator<<(std::ostream& os, const Vec2& v) {
        return os << "(" << v.x << ", " << v.y << ")";
    }
};

Exercise 2 — Stream output

Exercise 3 — Equality

Implement == operator

friend bool operator==(const Vec2& a, const Vec2& b) {
    return a.x == b.x && a.y == b.y;
}

Exercise 4 — Subtraction symmetry

Support both v - 3 and 3 - v

Vec2 operator-(int t) const {
    return {x - t, y - t};
}

friend Vec2 operator-(int t, const Vec2& v) {
    return {t - v.x, t - v.y};
}
---

Exercise 5 — Multiply scalar

friend Vec2 operator*(int t, const Vec2& v) {
    return v * t;
}
---

Exercise 6 — Dot product

Implement v1 * v2 → scalar

friend double operator*(const Vec2& a, const Vec2& b) {
    return a.x * b.x + a.y * b.y;

Exercise 7 — Mixed operations

Support: 2 + v + 3

// relies on chaining

9. Final Rules Cheat Sheet

  • Use member → when modifying object (+=, -=)
  • Use friend → when left operand is not your class
  • Use both → for symmetry
  • Keep logic in one place
---

10. Key Insight

Friend operators are NOT about syntax—they are about control of access + symmetry.
