02functions overloading

Overload linearTodB: one version takes double linearPower; another takes double linearPower and double refPower and returns 10·log10(linearPower/refPower) (guard refPower > 0).

#include <cmath>

double linearTodB(double const linearPower)
{
    return 10.0 * std::log10(linearPower);
}

double linearTodB(double const linearPower, double const refPower)
{
    if (refPower <= 0.0) {
        return 0.0;
    }
    return 10.0 * std::log10(linearPower / refPower);
}
03functions templates

Write a function template clampAbs(T value, T limit) that returns value clamped to [-limit, limit] with simple comparisons (no STL containers or algorithms).

template <typename T>
T clampAbs(T const value, T const limit)
{
    if (value < -limit) {
        return -limit;
    }
    if (value > limit) {
        return limit;
    }
    return value;
}

36Polymorphism at different levels

Given Processor from 34, write double run(Processor& p, double x) and double run(Passthrough& p, double x) to contrast dynamic dispatch vs static binding.

class Processor
{

class Passthrough : public Processor
{
public:
    double tick(double const x) override { return x; }

{
    return p.tick(x); // dynamic dispatch via vtable
}

double run(Passthrough& p, double const x)
{
    return p.tick(x); // static resolution to Passthrough::tick
}

42operator overloading (left and right, inheritance)

Base class Mono holds double e_; derived class Stereo : public Mono adds double eR_. Define Stereo operator+(Stereo const& a, Stereo const& b) summing both channels (use accessors or friends as you prefer).

class Mono
{
public:
    explicit Mono(double const e)
        : e_{e}
    {
    }

    double energy() const { return e_; }

protected:
    double e_;
};

class Stereo : public Mono
{
public:
    Stereo(double const left, double const right)
        : Mono{left}
        , eR_{right}
    {
    }

    double right() const { return eR_; }

    friend Stereo operator+(Stereo const& a, Stereo const& b);

private:
    double eR_;
};

Stereo operator+(Stereo const& a, Stereo const& b)
{
    return Stereo{a.energy() + b.energy(), a.right() + b.right()};
}
