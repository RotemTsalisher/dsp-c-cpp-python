02functions overloading

Overload adcToVolts: (a) double adcToVolts(int rawCount) assumes 16-bit full scale → maps to ±1.0 V; (b) double adcToVolts(int rawCount, double fullScaleVolts) uses the same count range but a caller-supplied reference voltage.

double adcToVolts(int const rawCount)
{
    return adcToVolts(rawCount, 1.0);
}

double adcToVolts(int const rawCount, double const fullScaleVolts)
{
    double const normalized = static_cast<double>(rawCount) / 32768.0;
    return normalized * fullScaleVolts;
}

Note: Overloading lets factory trim pass a measured reference while lab code keeps a default full-scale.

03functions templates

Template template<typename T> T saturate(T x, T lo, T hi) clamping x to [lo, hi] with comparisons only (no STL).

template <typename T>
T saturate(T const x, T const lo, T const hi)
{
    if (x < lo) {
        return lo;
    }
    if (x > hi) {
        return hi;
    }
    return x;
}

Note: One template serves int register fields and floating comb feedback without duplicating clamp logic.

05lambda functions

Lambda capturing double knee by value: soft-limit a sample with x / (1.0 + std::abs(x) / knee) (gentle AFE headroom before hard clip).

#include <cmath>

double softLimit(double const knee, double const x)
{
    auto const shaper = [knee](double const xi) {
        return xi / (1.0 + std::abs(xi) / knee);
    };
    return shaper(x);
}

Note: Capturing knee by value keeps the lambda reusable across a buffer without dangling references.

06requires

template<typename T> T wrapBinIndex(T idx, T nBins) with requires std::is_integral_v<T> returning (idx % nBins + nBins) % nBins for circular PSD bin indexing.

#include <type_traits>

08passing functions as arguments

double cascadeGain(double x, ShaperFn fn, int stages) where ShaperFn = double (*)(double); apply fn to x exactly stages times (serial gain staging).

using ShaperFn = double (*)(double);

double cascadeGain(double x, ShaperFn const fn, int const stages)

10fold expressions : reading / coding exe for differencing between left and right folds

For three comb tap gains g0, g1, g2, write both double leftChain = (1.0 * ... * g); and double rightChain = (g * ... * 1.0); in a comment or snippet — state whether they differ for multiplication and why associativity matters for numerics.

template <typename... Ts>
constexpr double leftMul(Ts... gains)
{
    return (1.0 * ... * gains); // init on the left
}

template <typename... Ts>
constexpr double rightMul(Ts... gains)
{
    return (gains * ... * 1.0); // init on the right
}

static_assert(leftMul(0.9, 0.8, 0.7) == rightMul(0.9, 0.8, 0.7));

// For * over reals both folds yield the same product; they differ syntactically
// and would diverge for non-commutative operators or mixed-precision staging.

Note: Left vs right fold syntax differs; for * the result is the same but the expansion order is not identical in the abstract syntax tree.

15create and manage threads using std::thread, including launching functions, joining, detaching, and passing arguments safely

Launch a worker thread that writes peak-hold maxAbs from four fixed samples passed by value into a shared double peakOut (by reference), then join(). Do not detach in this drill.

#include <cmath>
#include <thread>

int main()
{
    double peakOut = 0.0;
    double const s0 = -0.3;
    double const s1 = 0.9;
    double const s2 = 0.1;
    double const s3 = -0.6;

    std::thread worker([&peakOut, s0, s1, s2, s3]() {
        peakOut = std::max({std::abs(s0), std::abs(s1), std::abs(s2), std::abs(s3)});
    });
    worker.join();
    return 0;
}

Note: Capture shared state by reference, inputs by value — safe join before reading peakOut.

47Classes: operator overloading (left hand operators and right hand operators, members vs non members operators, symmetry, inheritance)

class CombTapPair holds double dry_, double wet_; member CombTapPair operator+(CombTapPair const& rhs) const; friend non-member CombTapPair operator*(double k, CombTapPair const& p) scaling both taps.

class CombTapPair
{
public:
    CombTapPair(double const dry, double const wet)
        : dry_{dry}
        , wet_{wet}
    {
    }

    CombTapPair operator+(CombTapPair const& rhs) const
    {
        return CombTapPair{dry_ + rhs.dry_, wet_ + rhs.wet_};
    }

    double dry() const { return dry_; }
    double wet() const { return wet_; }

    friend CombTapPair operator*(double k, CombTapPair const& p);

private:
    double dry_;
    double wet_;
};

CombTapPair operator*(double const k, CombTapPair const& p)
{
    return CombTapPair{k * p.dry_, k * p.wet_};
}

Note: Member + for same-type combine; free operator* on the left keeps scalar gain symmetric and readable.

std::map<std::string, std::uint32_t> AFE register table; function std::uint32_t lookupOffset(std::map<std::string, std::uint32_t> const& m, std::string const& name) returning offset or 0 if missing.

#include <cstdint>
#include <map>
#include <string>

std::uint32_t lookupOffset(
    std::map<std::string, std::uint32_t> const& m,
    std::string const& name)
{
    auto const it = m.find(name);
    if (it == m.end()) {
        return 0u;
    }
    return it->second;
}

Note: map::find avoids inserting a zero entry when a register name is absent from the table.
