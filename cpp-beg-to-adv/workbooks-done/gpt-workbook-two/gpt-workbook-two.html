C++ Workout 02

Exercise 1 – Namespaces + Overloading

Create two namespaces: logicA and logicB. Each namespace must implement two overloaded functions: 

int transform(int);
double transform(double);

logicA multiplies by 10. logicB divides by 10. Demonstrate calls to all four overloads.

#include <iostream> namespace logicA { int transform(int x) { return x * 10; } double transform(double x) { return x * 10; } } namespace logicB { int transform(int x) { return x / 10; } double transform(double x) { return x / 10; } } int main() { std::cout << logicA::transform(5) << "\n"; std::cout << logicA::transform(5.5) << "\n"; std::cout << logicB::transform(50) << "\n"; std::cout << logicB::transform(50.0) << "\n"; }

Exercise 2 – constexpr + Function Pointer

Create a constexpr function: 

constexpr int cube(int);

Create a function pointer to cube. Call it at runtime and also use it in a constexpr variable.

#include <iostream> constexpr int cube(int x) { return x * x * x; } int main() { constexpr int val = cube(3); int (*func)(int) = cube; std::cout << val << "\n"; std::cout << func(4) << "\n"; }

Exercise 3 – Variable Template Trait + requires

Create a variable template trait: 

is_integral_type_v<T>

It should evaluate to true only for integral types. Then create a function template: 

increment(T value)

It must only accept integral types using requires.

#include <iostream> #include <type_traits> template <typename T> constexpr bool is_integral_type_v = std::is_integral_v<T>; template <typename T> requires is_integral_type_v<T> T increment(T value) { return value + 1; } int main() { std::cout << increment(5) << "\n"; }

Exercise 4 – Struct Trait + Specialization + constexpr

Create a struct-based trait: 

type_multiplier<T>

Default multiplier = 1 Specialize for double so multiplier = 2 Create a constexpr function: 

apply_multiplier(T value)

Return value * type_multiplier<T>::value

#include <iostream> template <typename T> struct type_multiplier { static constexpr int value = 1; }; template <> struct type_multiplier<double> { static constexpr int value = 2; }; template <typename T> constexpr T apply_multiplier(T value) { return value * type_multiplier<T>::value; } int main() { constexpr int a = apply_multiplier(5); constexpr double b = apply_multiplier(3.0); std::cout << a << "\n"; std::cout << b << "\n"; }

Exercise 5 – Fold Expression + requires

Create a variadic template function: 

multiply_all(...)

- Use a fold expression - Accept only arithmetic types using requires

#include <iostream> #include <type_traits> template <typename... Args> requires (std::is_arithmetic_v<Args> && ...) auto multiply_all(Args... args) { return (args * ...); } int main() { std::cout << multiply_all(2,3,4) << "\n"; }

Exercise 6 – Passing Lambda as Argument

Create a function: 

apply_operation(int a, int b, function pointer)

Pass a lambda to it. The lambda should subtract b from a.

#include <iostream> int apply_operation(int a, int b, int (*op)(int,int)) { return op(a,b); } int main() { auto lambda = [](int x, int y) { return x - y; }; std::cout << apply_operation(10,5,lambda) << "\n"; }

Exercise 7 – Threads + Variadic Template Mix

Create a variadic template function: 

print_sum(...)

It must: - Use fold expression to sum arguments - Launch a thread that prints the result - Join the thread

#include <iostream> #include <thread> template <typename... Args> auto compute_sum(Args... args) { return (args + ...); } template <typename... Args> void print_sum(Args... args) { auto result = compute_sum(args...); std::thread t([result]() { std::cout << result << "\n"; }); t.join(); } int main() { print_sum(1,2,3,4); }
