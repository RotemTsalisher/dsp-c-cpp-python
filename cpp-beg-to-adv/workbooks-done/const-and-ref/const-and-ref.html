C++ OOP Workbook: Const Members & Reference Members

This workbook teaches two important C++ object-oriented programming concepts from scratch.

Part 1 — Const Member Variables

Concept

A const member variable is a class variable whose value cannot change after the object is created. 

class Circle {

private:
    const double pi;

public:
    Circle() : pi(3.14159) {}

};

Rules

  • A const member MUST be initialized in the constructor initializer list.
  • It cannot be assigned inside the constructor body.
  • After construction the value cannot change.
class Example {

private:
    const int x;

public:
    Example(int value) : x(value) {}

};

Exercise 5 – Bank Account

Design class BankAccount
  • const account_number
  • balance
  • deposit()
  • withdraw()
class BankAccount {

private:

    const int account_number;
    double balance;

public:

    BankAccount(int num, double bal)
        : account_number(num), balance(bal) {}

    void deposit(double amount)
    {
        balance += amount;
    }

    void withdraw(double amount)
    {
        balance -= amount;
    }

};

Part 2 — Reference Member Variables

Concept

A reference member stores a reference to another variable instead of owning its own copy. 

class Counter {

private:
    int& value;

public:
    Counter(int& v) : value(v) {}

};

Rules

  • Reference members MUST be initialized in the initializer list.
  • They cannot be reseated.
  • They always refer to the same variable.

Exercise 1 – Simple Modifier

Store a reference to an int and increment it. 
class Modifier {

private:
    int& value;

public:

    Modifier(int& v)
        : value(v) {}

    void increment()
    {
        value++;
    }

};
