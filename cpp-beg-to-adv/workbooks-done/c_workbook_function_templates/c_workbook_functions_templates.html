C++ Workbook – Functions & Templates

Solve each exercise before revealing the solution.

1. Functions

Exercise 1: Write a function square that returns the square of a number.

int square(int x) {
    return x * x;
}

Exercise 2: Write a function that swaps two integers using references.

void swap(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}

2. Function Overloading

Exercise 3: Overload print for int and double.

void print(int x) { std::cout << x; }
void print(double x) { std::cout << x; }

3. Function Templates

Exercise 4: Write a template function maxVal.

template
T maxVal(T a, T b) {
    return (a > b) ? a : b;
}

4. Template Specialization

Exercise 5: Specialize maxVal for const char*.

template<>
const char* maxVal(const char* a, const char* b) {
    return (std::strcmp(a,b) > 0) ? a : b;
}

5. Lambda Functions

Exercise 6: Write a lambda that computes cube.

auto cube = [](int x){ return x*x*x; };

6. Requires

Exercise 7: Constrain template to arithmetic types.

template
requires std::is_arithmetic_v
T add(T a, T b) { return a + b; }

7. Function Pointers

Exercise 8: Declare pointer to function returning int.

8. Passing Functions as Arguments

Exercise 9: Function taking callable.

9. Fold Expressions & Parameter Packs

Exercise 10: Sum variadic args.

template

10. Constexpr

Exercise 11: Constexpr factorial.

constexpr int fact(int n) {
    return (n <= 1) ? 1 : n * fact(n-1);
}

11. Traits (Variable / Struct Templates)

Exercise 12: Implement is_pointer trait.
