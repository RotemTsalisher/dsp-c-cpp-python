C++ Workbook 04

Exercise 1 – Basic Class + Getter / Setter

Create a class Counter with:

  • Private integer member value
  • Setter set(int)
  • Getter get()
  • Function increment() that increases the value

Demonstrate usage in main().

#include <iostream> class Counter{ private: int value; public: void set(int v){ value = v; } int get() const{ return value; } void increment(){ value++; } }; int main(){ Counter c; c.set(5); c.increment(); std::cout << c.get() << "\n"; }

Exercise 2 – Function Template + Class

Create a template function:

square(T value)

Then create a class Calculator with a method:

compute_square(T value)

It must call the template function.

#include <iostream> template<typename T> T square(T value){ return value * value; } class Calculator{ public: template<typename T> T compute_square(T v){ return square(v); } }; int main(){ Calculator c; std::cout << c.compute_square(5) << "\n"; }

Exercise 3 – Concept + requires

Create a concept:

Arithmetic

It should accept arithmetic types.

Create a function:

add(T a, T b)

It must use the concept.

#include <iostream> #include <type_traits> template<typename T> concept Arithmetic = std::is_arithmetic_v<T>; template<Arithmetic T> T add(T a, T b){ return a + b; } int main(){ std::cout << add(3,4) << "\n"; }

Exercise 4 – Traits + Class Interaction

Create trait:

is_floating_type_v<T>

Then create class TypeChecker with function:

check(T value)

Print whether the type is floating or not.

#include <iostream> #include <type_traits> template<typename T> constexpr bool is_floating_type_v = std::is_floating_point_v<T>; class TypeChecker{ public: template<typename T> void check(T value){ if constexpr(is_floating_type_v<T>) std::cout << "floating\n"; else std::cout << "not floating\n"; } }; int main(){ TypeChecker t; t.check(5); t.check(3.14); }

Exercise 5 – Fold Expression + Concept

Create a concept that accepts arithmetic types.

Create variadic function:

sum_all(...)

Use fold expression to sum arguments.

#include <iostream> #include <type_traits> template<typename T> concept Arithmetic = std::is_arithmetic_v<T>; template<Arithmetic... Args> auto sum_all(Args... args){ return (args + ...); } int main(){ std::cout << sum_all(1,2,3,4) << "\n"; }

Exercise 6 – Class + Lambda + Function Pointer

Create class OperationRunner.

It should have a function:

run(int a, int b, int(*op)(int,int))

Call the function pointer inside.

Pass a lambda from main().

#include <iostream> class OperationRunner{ public: int run(int a, int b, int(*op)(int,int)){ return op(a,b); } }; int main(){ OperationRunner r; auto add = [](int a, int b){ return a + b; }; std::cout << r.run(5,3,add) << "\n"; }

Exercise 7 – Threads + Class

Create class Worker with function:

do_work(int value)

It prints the value.

Launch two threads that call this method.

#include <iostream> #include <thread> class Worker{ public: void do_work(int value){ std::cout << value << "\n"; } }; int main(){ Worker w; std::thread t1(&Worker::do_work, &w, 10); std::thread t2(&Worker::do_work, &w, 20); t1.join(); t2.join(); }
