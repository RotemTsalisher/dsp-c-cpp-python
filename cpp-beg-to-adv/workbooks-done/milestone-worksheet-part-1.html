Part 1 — Topic Exercises

1. Functions

Write a function square() that receives a number and returns its square. Create a program that calls the function for 5 different numbers. 

int square(int x){
    return x*x;
}

2. Function Overloading

Create overloaded versions of a function add() that work for:

  • two integers
  • two doubles
  • three integers
int add(int a,int b){ return a+b; }

double add(double a,double b){ return a+b; }

int add(int a,int b,int c){ return a+b+c; }

3. Function Templates

Create a template function max_val() that returns the maximum between two values of any type. 

template
T max_val(T a,T b){
    return (a>b)?a:b;
}

4. Template Specialization

Specialize the template max_val() for const char* so that strings are compared using strcmp. 

template<>
const char* max_val(const char* a,const char* b){
    return strcmp(a,b)>0 ? a : b;
}

5. Lambda Functions

Create a lambda that calculates the cube of a number and use it inside a loop. 

auto cube = [](int x){ return x*x*x; };

6. Function Pointers

Create two functions:

  • add
  • multiply
Use a function pointer to choose which operation to execute. 

int (*operation)(int,int);
operation = add;

7. Passing Functions as Arguments

Write a function compute() that receives:

  • two integers
  • a function pointer
and applies the function to the integers. 

int compute(int a,int b,int (*op)(int,int)){
    return op(a,b);
}

8. Fold Expressions

Create a variadic template function that sums any number of arguments. 

template
auto sum(Args... args){
    return (... + args);
}

9. constexpr

Write a constexpr factorial() function. 

constexpr int factorial(int n){
    return n<=1 ? 1 : n*factorial(n-1);
}

10. Intro to Classes

Create a class Car with:

  • speed
  • fuel

class Car{
public:
    int speed;
    int fuel;
};

11. Encapsulation

Make the members private and implement getters/setters. 

class Car{

private:
    int speed;

public:

    void set_speed(int s){
        speed=s;
    }

    int get_speed(){
        return speed;
    }
};

12. Constructors

Add:

  • default constructor
  • constructor with parameters
Car():speed(0){}
Car(int s):speed(s){}

13. Destructors

Add a destructor that prints when an object is destroyed. 

~Car(){
    cout<<"Car destroyed";
}
