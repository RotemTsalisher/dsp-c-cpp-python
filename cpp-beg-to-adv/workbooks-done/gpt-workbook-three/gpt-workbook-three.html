C++ Workout 03

Exercise 1 – Namespaces + Template Overloading + requires

Create two namespaces: nsA and nsB. Each namespace must implement: template function: transform(T value) Requirements: - Accept arithmetic types only using requires - nsA multiplies value by 2 - nsB multiplies value by 5 Demonstrate calls for int and double.

#include <iostream> #include <type_traits> namespace nsA { template <typename T> requires std::is_arithmetic_v<T> T transform(T value) { return value * 2; } } namespace nsB { template <typename T> requires std::is_arithmetic_v<T> T transform(T value) { return value * 5; } } int main() { std::cout << nsA::transform(3) << "\n"; std::cout << nsB::transform(3.0) << "\n"; }

Exercise 2 – constexpr + Specialization Interaction

Create a struct trait: power_factor<T> Default factor = 1 Specialize for int so factor = 2 Create constexpr function: power(T value) Return value raised to power_factor<T> using multiplication only.

#include <iostream> template <typename T> struct power_factor { static constexpr int value = 1; }; template <> struct power_factor<int> { static constexpr int value = 2; }; template <typename T> constexpr T power(T value) { if constexpr (power_factor<T>::value == 1) return value; else return value * value; } int main() { constexpr int a = power(3); constexpr double b = power(3.5); std::cout << a << "\n"; std::cout << b << "\n"; }

Exercise 3 – Variable Trait + Fold Expression Constraint

Create a variable template trait: is_same_type_v<T,U> True only if T and U are the same type. Create variadic template: check_all_same(first, rest...) Return true only if all arguments are same type as first. Use fold expression.

#include <iostream> #include <type_traits> template <typename T, typename U> constexpr bool is_same_type_v = std::is_same_v<T,U>; template <typename T, typename... Args> constexpr bool check_all_same(T, Args... args) { return (is_same_type_v<T, Args> && ...); } int main() { std::cout << check_all_same(1,2,3) << "\n"; std::cout << check_all_same(1,2.0) << "\n"; }

Exercise 4 – Function Pointer + Lambda + Passing Function

Create function: operate(int a, int b, int(*op)(int,int)) Inside main: - Create two lambdas (add and multiply) - Pass them to operate - Also store one in a function pointer

#include <iostream> int operate(int a, int b, int(*op)(int,int)) { return op(a,b); } int main() { auto add = [](int x, int y) { return x + y; }; auto multiply = [](int x, int y) { return x * y; }; int (*func)(int,int) = add; std::cout << operate(3,4,add) << "\n"; std::cout << operate(3,4,multiply) << "\n"; std::cout << func(5,6) << "\n"; }

Exercise 5 – requires + Fold + Arithmetic Enforcement

Create variadic template: average(...) Requirements: - Accept arithmetic types only - Use fold expression - Return arithmetic mean

#include <iostream> #include <type_traits> template <typename... Args> requires (std::is_arithmetic_v<Args> && ...) auto average(Args... args) { auto sum = (args + ...); return sum / sizeof...(args); } int main() { std::cout << average(2,4,6) << "\n"; }

Exercise 6 – Threads + Namespace + Function Template

Create namespace worker. Inside it create template function: run_task(T value) It prints value. In main: - Launch two threads using worker::run_task - Use different types - Join threads

#include <iostream> #include <thread> namespace worker { template <typename T> void run_task(T value) { std::cout << value << "\n"; } } int main() { std::thread t1(worker::run_task<int>, 10); std::thread t2(worker::run_task<double>, 3.14); t1.join(); t2.join(); }

Exercise 7 – Full Mix: Traits + requires + Fold + Thread

Create trait: is_positive_integral_v<T> True only for integral types. Create variadic function: process_values(...) Requirements: - Accept only integral types (requires) - Use fold expression to sum - Launch thread that prints the result - Join thread

#include <iostream> #include <thread> #include <type_traits> template <typename T> constexpr bool is_positive_integral_v = std::is_integral_v<T>; template <typename... Args> requires (is_positive_integral_v<Args> && ...) void process_values(Args... args) { auto result = (args + ...); std::thread t([result]() { std::cout << result << "\n"; }); t.join(); } int main() { process_values(1,2,3,4); }
