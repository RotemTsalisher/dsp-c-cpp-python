C++ Workout 01

Exercise 1 – Namespace + Basic Functions

Create two namespaces: mathA and mathB. Each namespace must implement a function: 

int compute(int x);

mathA::compute returns x * 2 mathB::compute returns x * 3 In main(), demonstrate that naming collisions are prevented.

#include <iostream> namespace mathA { int compute(int x) { return x * 2; } } namespace mathB { int compute(int x) { return x * 3; } } int main() { std::cout << mathA::compute(5) << "\n"; std::cout << mathB::compute(5) << "\n"; }

Exercise 2 – Overloading + constexpr

Create two overloaded functions named square: 

int square(int);
double square(double);

Both must be constexpr. Demonstrate compile-time evaluation using a constexpr variable.

#include <iostream> constexpr int square(int x) { return x * x; } constexpr double square(double x) { return x * x; } int main() { constexpr int a = square(5); constexpr double b = square(3.0); std::cout << a << "\n"; std::cout << b << "\n"; }

Exercise 3 – Templates + requires

Create a function template: 

add(T a, T b)

It must: - Only accept arithmetic types - Use requires

#include <iostream> #include <type_traits> template <typename T> requires std::is_arithmetic_v<T> T add(T a, T b) { return a + b; } int main() { std::cout << add(3, 4) << "\n"; std::cout << add(3.5, 2.1) << "\n"; }

Exercise 4 – Traits + Specialization

Create a trait struct: 

is_pointer_type<T>

Default value = false Specialize for T* so value = true Demonstrate usage with static_assert.

#include <type_traits> template <typename T> struct is_pointer_type { static constexpr bool value = false; }; template <typename T> struct is_pointer_type<T*> { static constexpr bool value = true; }; static_assert(is_pointer_type<int*>::value); static_assert(!is_pointer_type<int>::value); int main() {}

Exercise 5 – Fold Expressions + Function Pointers

Create a variadic template function: 

sum_all(...)

Use a fold expression to sum arguments. Then: Create a function pointer to this function and invoke it.

#include <iostream> template <typename... Args> auto sum_all(Args... args) { return (args + ...); } int main() { int (*func)(int, int, int) = nullptr; auto wrapper = [](int a, int b, int c) { return sum_all(a, b, c); }; func = wrapper; std::cout << func(1,2,3) << "\n"; }

Exercise 6 – Threads + Passing Functions as Arguments

Create a function: 

void print_times(int value, int times);

Launch two threads calling this function with different values. Join the threads.

#include <iostream> #include <thread> void print_times(int value, int times) { for(int i = 0; i < times; ++i) { std::cout << value << "\n"; } } int main() { std::thread t1(print_times, 1, 5); std::thread t2(print_times, 2, 5); t1.join(); t2.join(); }
