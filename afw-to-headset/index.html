From a block change to a flashed headset

The VST course stops when Bidule can load your plugin. This course starts there and walks the rest of the path that actually ships audio on Apollo: the same C module, compiled again for HiFi4, linked into the DSP image, packed with the Cortex-M33 image, stored in the QCC filesystem, and flashed.

עברית

זה ההמשך של קורס ה-VST. שם בונים מודול וטוענים אותו ב-Bidule. כאן הולכים עד האוזנייה: שינוי בלוק, קומפילציית VST, ספריית Xtensa (החלק שדורש צעדים קטנים), אימג' DSP ואז ARM, אימג' QCC, וצריבה. הדוגמה החיה היא יציאת I2S שקטה על GoPro: מיקסר וראוטר מ-8×8 ל-12×12, בלי לשנות את מה שהרמקול מנגן. קומפילציה ירוקה של VST לא אומרת שהאוזנייה קיבלה את השינוי.

How to use this course

One step, then you do it, then you stop and check the checkpoint. Pages 05 and 06 are the slow pages on purpose. A mentor can sit beside you; the commands below are the ones that match this tree, not a generic embedded tutorial.

Prerequisite

Finish audio-framework-vst/ first. You should already know AudioModuleCore, GenericProcessor, ioConfigs, and how a .vst3 is built from Modules/VST3Plugins.sln. This course does not reteach Gain.

The two trees

  • c:\repo\AudioFramework — modules, VST projects, Bidule graphs, the Xtensa library project Builds\CSL_AFW.
  • c:\repo\Cardo_Products_Apollo\Cardo_Products — the headset. DSP, ARM, QCC, and the copy of the library the firmware links.

Branch products from develop_apollo. Branch Audio Framework from main. The CRM main checkout of products is a different line.

What you will be able to do

Change a block (C + pin list, not the JUCE wrapper) ↓ VST3 Release x64 → Bidule listens on the PC ↓ Graph header (GoPro48.h) is a separate file from the library header ↓ xt-xcc builds CSL_AFW.a twice (with Sensory, and without) ↓ copy_libs.bat renames them — the names are not what the folders suggest ↓ Only CSL_AFW_SNSR.a + CSL_AFW.h move into nxp\libs\CSL_AFW ↓ DSP image (HiFi4), then ARM image, then nxp_boot_image.bin ↓ QCC headset image packs that bin and is what you flash

Worked example used on every page

A silent stereo tap on GoPro only. Mixer and router grow from 8×8 to 12×12 and stay square. Mixer outputs 1 and 2 still feed NDVC, EQ, and the existing limiter, then the speaker. Mixer outputs 9 and 10, at gain 0, go through a second limiter (the existing 2×2 layout) into router inputs 9 and 10, and those leave on router outputs 7 and 8, which process_afw already copies to I2S0. Flow, Kido, PT3 Pro, and GoPro 16 kHz stay as they are. The method is the same the next time the block is a different one.
