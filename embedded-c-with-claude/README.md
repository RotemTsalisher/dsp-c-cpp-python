# Embedded C with Claude Code — Companion Course

**Parallel to:** [Microcontroller Embedded C Programming: Absolute Beginners](https://www.udemy.com/course/microcontroller-embedded-c-programming/) (FastBit Embedded Brain Academy)

## What This Is
An AI-accelerated companion course that follows the Udemy syllabus **section by section**. For each topic you learn in the Udemy lecture, this course teaches you how to use **Claude Code** to deepen understanding, generate code, debug problems, and build faster.

## Prerequisites
- Enrolled in (or have access to) the Udemy Embedded C course
- STM32F4 Discovery or Nucleo board
- STM32CubeIDE installed
- Claude Code CLI installed (`npm install -g @anthropic-ai/claude-code`)

## How to Use
1. Watch the Udemy lecture for a topic
2. Open `index.html` in your browser
3. Navigate to the matching module
4. Complete the exercises using Claude Code in your project

## Open the Course
Open `index.html` in any browser. Progress saves locally via localStorage.
