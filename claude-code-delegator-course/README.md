# Claude Code Works FOR Me — Delegation Mastery

A fundamentally different course: **you are the tech lead, Claude is the implementer.**

## The mindset

| ❌ Other courses teach | ✅ This course teaches |
|---|---|
| "I use Claude Code" | "Claude Code works for me" |
| Type prompts at a terminal | Write task briefs as markdown specs |
| Accept/reject each diff | Review finished branches like PRs |
| Interactive sessions | Headless delegation (`-p` flag) |
| You are the implementer | You are the reviewer |
| One prompt at a time | Orchestrated pipelines of tasks |
| Manual verification | Automated quality gates |

## Start

1. Open **`index.html`** in Chrome, Edge, or Firefox.
2. Work through modules **00 → 18** in order.
3. Create a `dsp-sandbox` project and practice delegation on real code.

## Prerequisites

- **Claude Code CLI** installed (`npm install -g @anthropic-ai/claude-code`)
- **A terminal** — headless mode is the primary interface
- **gcc / cmake** — for building delegated C work
- **Python 3.9+** — for golden vector generation

## What you will learn

- Writing task briefs (complete specs a junior developer could implement from)
- CLAUDE.md as an "employee handbook" (not project memory)
- Acceptance criteria that machines can verify (no subjective criteria)
- Verification scripts as quality gates
- Headless delegation as the default workflow
- Batch operations across entire codebases
- CI/CD pipelines with Claude as a worker
- Scheduled tasks (nightly, weekly, on-event)
- SDK-based programmatic delegation
- PR-based review workflows
- Multi-task orchestration with dependencies

## Contents

- **20 modules** · **84 exercises** with **Reveal solution** / **Mark complete**
- Progression: Pre-Setup → Beginner → Intermediate → Advanced → Expert → Daily Drills
- You write ZERO lines of implementation code. Every line is written by Claude.
