Traps that waste a flight

  • Encoding. In Windows PowerShell 5.1, > and Out-File write UTF-16. Compilers and git then show garbage. Use Set-Content -Encoding utf8 or pipe to it.
  • where is Where-Object, not “which”. Use where.exe g++ or Get-Command g++.
  • curl in 5.1 is Invoke-WebRequest. PowerShell 7 leaves curl alone.
  • && and || exist in PowerShell 7. In 5.1 they are a syntax error. Use ; and $LASTEXITCODE.
  • Backtick ` is the escape and the line-continue character. A trailing \ does not continue the line.
  • Quotes. Double quotes expand $variables. Single quotes are literal. Paths with spaces always get quotes: cd "C:\Program Files".
  • Copy into an existing folder. cp -Recurse src backup when backup already exists creates backup\src, a nested copy.
  • Delete is final. rm does not use the recycle bin. ls the wildcard, then rm ... -WhatIf, then delete.
  • Run a local exe as .\program.exe. A bare program.exe is searched on PATH and can miss the file you just built.
  • Clear the screen with cls. Ctrl+L is the Emacs-mode binding and often does nothing in the default Windows mode.
