# Syllabus — TI MSP430: Embedded C and Microcontroller Programming

**Hardware:** TI MSP-EXP430G2 LaunchPad (MSP430G2553)

## Global requirements
- 3 progressive exercises + 1 independent assignment per module
- Labs with expected results, test procedures, debugging guidance
- Solutions separate from learner-facing files
- Git-friendly project layout with build/flash/test documented

## Modules

1. **Embedded systems and MSP430 architecture**
2. **Toolchain and debugging workflow**
3. **GPIO and digital electronics**
4. **Clock system and low-power modes**
5. **Interrupts and event handling**
6. **Timer_A and timing systems**
7. **ADC10 and analog interfacing**
8. **PWM and actuator control**
9. **UART communication**
10. **SPI and I2C communication**
11. **Memory, watchdog, and reliability**
12. **Firmware architecture and real-time programming**
13. **Integration and final project**

## Final projects

- Sensor monitor / UART data logger
- PWM motor controller with external driver
- Serial command controller
- Timer-driven measurement system
