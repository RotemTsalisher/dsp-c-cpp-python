# Cursor Zero → Hero (Embedded DSP)

Interactive course for embedded / DSP engineers using **C, C++, and Python**.

## Start

1. Open **`index.html`** in Chrome, Edge, or Firefox (double-click or drag into the browser).
2. Work through modules **00 → 24** in order; use **Daily Drills** between sessions.
3. Create a sibling folder **`dsp-sandbox`** (or anywhere you like) and do every exercise in real code — the course is hands-on.

## Regenerate (optional)

If you edit `generate_course.py`:

```bash
python generate_course.py
```

Progress is stored in your browser (`localStorage`), not in files.
