# Syllabus — Arduino UNO R4 Minima: Embedded Systems and DSP

**Hardware:** Arduino UNO R4 Minima (Renesas RA4M1, Cortex-M4 + FPU)

## Global requirements
- 3 progressive exercises + 1 independent assignment per module
- Labs with expected results, test procedures, debugging guidance
- Solutions separate from learner-facing files
- Git-friendly project layout with build/flash/test documented

## Modules

1. **Arduino and RA4M1 architecture**
2. **Embedded C/C++**
3. **GPIO and digital logic**
4. **Timers, counters, and PWM**
5. **Interrupts and event handling**
6. **ADC, DAC, and analog interfacing**
7. **UART, SPI, and I2C**
8. **Memory and data structures**
9. **ARM Cortex-M4 and low-level programming**
10. **DMA and data movement**
11. **Real-time firmware architecture**
12. **Debugging, testing, and optimization**
13. **Final embedded systems project**

## Final projects

- Analog audio I/O with external front-end + DSP block
- Programmable waveform generator (DAC + reconstruction filter)
- FIR/IIR processor on live ADC stream
- Real-time spectrum analyzer
