Subject 1: C Fundamentals & Compilation Model

Medium
Exercise 1.1 — ADC Fixed-Point Raw Sample Normalization
An Audio Front End (AFE) hardware analog-to-digital converter returns raw 16-bit signed integer PCM samples in the range [-32768, 32767]. Write an ANSI C function float normalize_sample(int16_t raw_adc) that explicitly converts raw ADC counts into a normalized floating-point audio sample in the range [-1.0f, 1.0f]. Ensure full precision during division and avoid implicit lossy casting. 
#include <stdint.h>

float normalize_sample(int16_t raw_adc) {
    if (raw_adc < 0) {
        return (float)raw_adc / 32768.0f;
    } else {
        return (float)raw_adc / 32767.0f;
    }
}
Why this works & C concepts used: Uses explicit casting (float)raw_adc before division to prevent integer truncation. Assures floating-point literal division (32768.0f) so the compiler emits single-precision floating-point instructions rather than double-precision overhead.
Hard
Exercise 1.2 — Immutability Bounds in Static Audio Filter Coefficients
Design a C interface for an Audio DSP FIR Filter module where coefficient tables stored in flash memory must be strictly protected against accidental runtime alteration by application code. Declare the initialization signature and function body void fir_init(const float* const coeffs, uint32_t num_taps) that assigns the pointer to a module-scoped static structure while enforcing pointer address immutability and target data read-only protection. 
#include <stdint.h>
#include <stddef.h>

typedef struct {
    const float* coeff_ptr;
    uint32_t tap_count;
} FirHandle_t;

static FirHandle_t g_fir_instance;

void fir_init(const float* const coeffs, uint32_t num_taps) {
    if (coeffs == NULL || num_taps == 0) return;
    g_fir_instance.coeff_ptr = coeffs;
    g_fir_instance.tap_count = num_taps;
}
Why this works & C concepts used: Demonstrates dual const qualifier usage: const float* const coeffs specifies that neither the array elements nor the pointer variable itself can be mutated within the compilation unit, placing constant tables into the read-only data segment (.rodata).

Exercise 2.1 — Safe Multi-Statement Preprocessor Macro for Gain Scaling
Write a preprocessor macro SCALE_AFE_CHANNEL(channel_ptr, gain_factor, clip_limit) that multiplies the audio channel sample by gain_factor and clamps it to clip_limit if exceeded. Construct the macro such that it safely executes in any control-flow structure (including unbracketed if-else branches) without introducing dangling else syntax bugs or scope leakage. 
#define SCALE_AFE_CHANNEL(channel_ptr, gain_factor, clip_limit) \
    do { \
        *(channel_ptr) = *(channel_ptr) * (gain_factor); \
        if (*(channel_ptr) > (clip_limit)) { \
            *(channel_ptr) = (clip_limit); \
        } \
    } while (0)
Why this works & C concepts used: Encapsulates multi-statement macro logic using the standard do { ... } while(0) idiom. This forces trailing semicolons to bind properly without breaking single-statement conditional execution blocks in nested control flow.

Subject 3: Data Aggregation, Memory Layout, and CPU Struct Alignment

Medium
Exercise 3.1 — Audio Packet Header Layout & Field Padding Analysis
Define a structure AudioFrameHeader_t representing a binary network audio frame containing: uint8_t sync_byte, uint64_t timestamp_ns, uint16_t sample_rate_hz, uint8_t channel_count, and uint32_t frame_index. Calculate the unpadded total size vs actual memory consumed on a 64-bit architecture, and write a function to return the total byte padding inserted by compiler alignment rules. 
#include <stdint.h>
#include <stddef.h>

typedef struct {
    uint8_t  sync_byte;       /* 1 byte + 7 padding bytes to align uint64_t */
    uint64_t timestamp_ns;    /* 8 bytes */
    uint16_t sample_rate_hz;  /* 2 bytes */
    uint8_t  channel_count;   /* 1 byte + 1 padding byte to align uint32_t */
    uint32_t frame_index;     /* 4 bytes */
} AudioFrameHeader_t;

size_t get_struct_padding(void) {
    size_t net_data_bytes = sizeof(uint8_t) + sizeof(uint64_t) + sizeof(uint16_t) + sizeof(uint8_t) + sizeof(uint32_t);
    size_t actual_struct_size = sizeof(AudioFrameHeader_t);
    return actual_struct_size - net_data_bytes;
}
Why this works & C concepts used: Demonstrates CPU memory alignment where fields are aligned to multi-byte word boundaries matching their type sizes. Shows how sizeof includes compiler-inserted padding bytes to ensure arrays of structs align correctly.
Hard
Exercise 3.2 — Struct Field Reordering for Memory Footprint Optimization
Reorder the fields of UnoptimizedBufferMeta_t to form OptimizedBufferMeta_t, minimizing memory padding. The structure contains: uint8_t valid, double max_amplitude, uint16_t num_channels, float peak_frequency, uint8_t muted, and uint64_t frame_id. Write a compile-time assertion check confirming the size reduction. 
#include <stdint.h>
#include <assert.h>

/* Reordered by decreasing size alignment: 8-byte, 4-byte, 2-byte, 1-byte */
typedef struct {
    double   max_amplitude;   /* 8 bytes */
    uint64_t frame_id;        /* 8 bytes */
    float    peak_frequency;  /* 4 bytes */
    uint16_t num_channels;    /* 2 bytes */
    uint8_t  valid;           /* 1 byte  */
    uint8_t  muted;           /* 1 byte  */
} OptimizedBufferMeta_t;      /* Total: 24 bytes (0 padding bytes) */

static_assert(sizeof(OptimizedBufferMeta_t) == 24, "Packing failed!");
Why this works & C concepts used: Grouping structure members by decreasing natural alignment constraints (8-byte primitives down to 1-byte flags) eliminates internal alignment gaps, compressing the structure footprint without relying on compiler-specific #pragma pack macros.

Subject 4: Pointers, Memory Addressing, and Virtual Memory Mapping

Medium
Exercise 4.1 — Parameter Mutation & Indirect Register Field Update
An audio gain controller hardware block is managed via a C configuration struct AfeGainConfig_t containing float pre_gain_db and float post_gain_db. Write a function void update_afe_gains(AfeGainConfig_t* cfg, float delta_db) that mutates both internal fields via arrow pointer dereferencing while checking for NULL pointer inputs. 
#include <stddef.h>

typedef struct {
    float pre_gain_db;
    float post_gain_db;
} AfeGainConfig_t;

void update_afe_gains(AfeGainConfig_t* cfg, float delta_db) {
    if (cfg == NULL) return;
    cfg->pre_gain_db += delta_db;
    cfg->post_gain_db += delta_db;
}
Why this works & C concepts used: Leverages pass-by-pointer to mutate calling scope state directly in memory. Syntactic arrow notation cfg->pre_gain_db dereferences the base pointer and computes field offset in process address space.

Exercise 4.2 — Virtual Memory Process Address Layout Inspector
Write a C function void inspect_process_memory_layout(void) that prints the virtual memory address locations of: a static global audio buffer, a local stack frame variable inside the function, a dynamic heap memory block, and a code segment function address. Classify which segment (Data, Stack, Heap, Text) each address belongs to based on relative layout ordering. 
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

static float g_global_audio_buffer[1024];

void inspect_process_memory_layout(void) {
    int local_stack_var = 42;
    float* heap_buffer = (float*)malloc(256 * sizeof(float));

    printf("Text Segment (Code):   %p\n", (void*)&inspect_process_memory_layout);
    printf("Global Data Segment:   %p\n", (void*)g_global_audio_buffer);
    printf("Heap Memory Segment:   %p\n", (void*)heap_buffer);
    printf("Stack Frame Segment:  %p\n", (void*)&local_stack_var);

    free(heap_buffer);
}
Why this works & C concepts used: Demonstrates process virtual address space partitioning. Code (Text) resides at low virtual addresses, globals sit in Data/BSS, the Heap grows upward from lower memory, and Stack frames grow downward from high memory boundaries.

Subject 5: Arrays, Pointer Arithmetic, and String Buffer Safety

Medium
Exercise 5.1 — Interleaved Stereo PCM Frame Unpacking via Pointer Arithmetic
An audio stream contains interleaved stereo samples [L0, R0, L1, R1, L2, R2...] stored in a contiguous float array. Write a function void deinterleave_pcm(const float* src, float* left_ch, float* right_ch, uint32_t num_frames) using raw pointer arithmetic (without bracket [] indexing) to extract left and right channels into separate buffers. 
#include <stdint.h>
#include <stddef.h>

void deinterleave_pcm(const float* src, float* left_ch, float* right_ch, uint32_t num_frames) {
    if (!src || !left_ch || !right_ch) return;
    
    for (uint32_t i = 0; i < num_frames; i++) {
        *(left_ch + i)  = *(src + (2 * i));
        *(right_ch + i) = *(src + (2 * i + 1));
    }
}
Why this works & C concepts used: Pointer arithmetic *(src + offset) automatically scales byte offsets by sizeof(float) (4 bytes). Demonstrates equivalence between pointer arithmetic and array indexing while traversing multi-channel memory blocks.
Hard
Exercise 5.2 — Safe Telemetry Log Buffer Formatting without Overflow
Implement a string formatting function size_t format_dsp_telemetry(char* dest_buf, size_t buf_capacity, uint32_t sample_rate, float snr_db) that safely appends telemetry key-value pairs without risking buffer overflows or missing null-terminators. Return the exact number of characters written or truncated. 
#include <stdio.h>
#include <stddef.h>
#include <stdint.h>

size_t format_dsp_telemetry(char* dest_buf, size_t buf_capacity, uint32_t sample_rate, float snr_db) {
    if (dest_buf == NULL || buf_capacity == 0) return 0;
    
    int written = snprintf(dest_buf, buf_capacity, "SR=%uHz;SNR=%.2fdB;", sample_rate, snr_db);
    
    if (written < 0) return 0;
    if ((size_t)written >= buf_capacity) {
        return buf_capacity - 1; /* Truncated, but null-terminated */
    }
    return (size_t)written;
}
Why this works & C concepts used: Uses snprintf bounds checking instead of hazardous sprintf or manual string copies. Ensures guaranteed null-termination (\0) even when the formatted payload exceeds destination buffer capacity.
