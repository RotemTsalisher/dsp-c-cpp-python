# C Programming and Memory Management Mastery — Cursor Workbook Pack

Welcome to the complete 10-Subject C Programming and Memory Management Workbook Pack, specially structured for **4th-Year Electrical Engineering (EE)** and **Audio Digital Signal Processing (DSP)** applications.

## 📁 Repository Structure
- `course-subjects.txt`: Complete 10-subject master list.
- `workbook_01_first_half_curriculum.html`: Subjects 1–5 (Compilation Model to Arrays/Strings).
- `workbook_02_second_half_curriculum.html`: Subjects 6–10 (Enums/Unions to Garbage Collector VM).
- `workbook_03_interview_style.html`: 4 Integrated EE/DSP Memory Management Interview Challenges.

## 🎯 Key Pedagogical Principles
1. **EE/DSP Context**: All exercises feature domain-specific scenarios (AFE gain, PCM frames, stereo deinterleaving, FIR filter guards, endianness, lock-free SPSC rings, Garbage Collector VM).
2. **Zero Hints in Visible Body**: Prompts are clean and challenge-focused.
3. **Interactive Reveal Toggles**: Solutions and `.why` explanations stay hidden behind `<button class="reveal-btn">` controls.
4. **ANSI C11 Compliance**: Clean, robust C code formatted with `stdint.h` types and defensive memory practices.

## 🚀 How to Use with Cursor / VS Code
1. Open any `.html` workbook file directly in your web browser by double-clicking it.
2. In Cursor, open `course-subjects.txt` alongside your C source files (`.c` / `.h`) to work through the exercises module by module.
