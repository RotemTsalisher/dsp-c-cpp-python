Exercise 6.1 — DSP Execution State Machine Control Flow
Define an enumeration DspState_t with states: DSP_STATE_INIT, DSP_STATE_RUNNING, DSP_STATE_PAUSED, and DSP_STATE_ERROR. Write a function const char* get_dsp_state_name(DspState_t state) utilizing a exhaustive switch-case jump table to return string descriptors while handling unknown enum values safely. 
typedef enum {
    DSP_STATE_INIT = 0,
    DSP_STATE_RUNNING,
    DSP_STATE_PAUSED,
    DSP_STATE_ERROR
} DspState_t;

const char* get_dsp_state_name(DspState_t state) {
    switch (state) {
        case DSP_STATE_INIT:    return "INITIALIZING";
        case DSP_STATE_RUNNING: return "RUNNING";
        case DSP_STATE_PAUSED:  return "PAUSED";
        case DSP_STATE_ERROR:   return "ERROR";
        default:                return "UNKNOWN_STATE";
    }
}
Why this works & C concepts used: Uses explicit C enums for finite state machine indexing. The switch statement enables compiler branch optimization, and returning string literals avoids heap allocation while guaranteeing static storage lifetime.

Exercise 6.2 — Hardware Type Punning for IEEE-754 Float Network Serialization
Construct a C union FloatPacket_t that overlays a 32-bit float audio sample float value with an array uint8_t raw_bytes[4] and a 32-bit unsigned integer uint32_t raw_bits. Write a function that inspects the raw bit pattern and sign bit of a IEEE-754 single-precision audio float without using void pointer typecasting. 
#include <stdint.h>
#include <stdbool.h>

typedef union {
    float    value;
    uint32_t raw_bits;
    uint8_t  raw_bytes[4];
} FloatPacket_t;

bool is_sample_negative(float sample, uint32_t* out_bits) {
    FloatPacket_t pkt;
    pkt.value = sample;
    if (out_bits) *out_bits = pkt.raw_bits;
    return (pkt.raw_bits & 0x80000000U) != 0;
}
Why this works & C concepts used: Uses C union memory overlay for type punning. All union members share the exact same starting memory address, permitting raw bitwise extraction (e.g., bit 31 sign extraction) without strict aliasing violations.

Subject 7: Memory Architecture: Hardware Stack vs. Dynamic Heap

Medium
Exercise 7.1 — Dynamic Delay Line Heap Allocation & Deallocation
Write functions float* create_delay_line(size_t length_samples) and void destroy_delay_line(float** delay_line_ptr). The allocation function must allocate heap memory using calloc to guarantee zero-initialized state, while the destruction function must free the block and set the caller's pointer to NULL to prevent dangling pointer bugs. 
#include <stdlib.h>

float* create_delay_line(size_t length_samples) {
    if (length_samples == 0) return NULL;
    float* buffer = (float*)calloc(length_samples, sizeof(float));
    return buffer; /* NULL if allocation failed */
}

void destroy_delay_line(float** delay_line_ptr) {
    if (delay_line_ptr != NULL && *delay_line_ptr != NULL) {
        free(*delay_line_ptr);
        *delay_line_ptr = NULL;
    }
}
Why this works & C concepts used: calloc allocates contiguous heap space while initializing all bytes to zero (essential for clean digital audio delay lines). Double pointer pass-by-reference allows zeroing out the caller's pointer variable after free().

Exercise 7.2 — Multi-Byte Endianness Swap for Binary Audio File Headers
Audio hardware communicates across big-endian network buses and little-endian host processors. Write a C function uint32_t swap_endian32(uint32_t val) and a runtime detection function bool is_system_little_endian(void) that determines CPU architecture byte ordering using raw pointer byte inspection. 
#include <stdint.h>
#include <stdbool.h>

uint32_t swap_endian32(uint32_t val) {
    return ((val >> 24) & 0x000000FF) |
           ((val >> 8)  & 0x0000FF00) |
           ((val << 8)  & 0x00FF0000) |
           ((val << 24) & 0xFF000000);
}

bool is_system_little_endian(void) {
    uint16_t test_word = 0x0100;
    uint8_t* byte_ptr = (uint8_t*)&test_word;
    return (byte_ptr[0] == 0x00);
}
Why this works & C concepts used: Inspects low-address byte representations of multi-byte primitive values. In little-endian platforms, the least significant byte is stored at the lowest memory address offset.

Subject 8: Multi-Level Indirection, Generic Pointers, and Raw Memory Operations

Medium
Exercise 8.1 — Multi-Track Audio Buffer Matrix Allocation via Pointer-to-Pointer
Implement dynamic dynamic matrix allocation for multi-channel audio recording: float** allocate_track_matrix(size_t num_tracks, size_t num_samples). The function must allocate an array of float pointers, then allocate each track buffer independently. Handle dynamic allocation failure mid-loop by unwinding previously allocated tracks without leaking heap memory. 
#include <stdlib.h>

float** allocate_track_matrix(size_t num_tracks, size_t num_samples) {
    if (num_tracks == 0 || num_samples == 0) return NULL;
    
    float** matrix = (float**)malloc(num_tracks * sizeof(float*));
    if (!matrix) return NULL;
    
    for (size_t i = 0; i < num_tracks; i++) {
        matrix[i] = (float*)calloc(num_samples, sizeof(float));
        if (!matrix[i]) {
            /* Cleanup already allocated tracks on failure */
            for (size_t j = 0; j < i; j++) {
                free(matrix[j]);
            }
            free(matrix);
            return NULL;
        }
    }
    return matrix;
}
Why this works & C concepts used: Employs double-indirection (float**) to manage two-dimensional dynamic data grids. Demonstrates robust error handling by unwinding partial heap allocations when allocation fails mid-loop.

Exercise 8.2 — Generic Raw Memory Buffer Swapping Function
Write a type-agnostic memory block swapping function void mem_swap(void* a, void* b, size_t byte_size) using untyped generic pointers (void*) and temporary byte-by-byte buffer swapping without assuming data primitive types. 
#include <stdint.h>
#include <stddef.h>
#include <stdlib.h>

void mem_swap(void* a, void* b, size_t byte_size) {
    if (!a || !b || byte_size == 0 || a == b) return;
    
    uint8_t* ptr_a = (uint8_t*)a;
    uint8_t* ptr_b = (uint8_t*)b;
    
    for (size_t i = 0; i < byte_size; i++) {
        uint8_t temp = ptr_a[i];
        ptr_a[i] = ptr_b[i];
        ptr_b[i] = temp;
    }
}
Why this works & C concepts used: Casts generic void* parameters to byte-addressable uint8_t* pointers, enabling polymorphic raw memory manipulations regardless of underlying structure or primitive types.

Subject 9: Dynamic Data Structures and Polymorphic Tagged Objects

Exercise 9.1 — Dynamic Resizable Audio Ring Buffer Expansion
Implement a dynamic array structure AudioRingBuf_t containing float* data, size_t capacity, and size_t count. Write a function bool ring_buf_push(AudioRingBuf_t* buf, float sample) that doubles buffer capacity using realloc when full while preserving existing sample sequence. 
#include <stdlib.h>
#include <stdbool.h>

typedef struct {
    float* data;
    size_t capacity;
    size_t count;
} AudioRingBuf_t;

bool ring_buf_push(AudioRingBuf_t* buf, float sample) {
    if (!buf) return false;
    
    if (buf->count >= buf->capacity) {
        size_t new_cap = (buf->capacity == 0) ? 128 : buf->capacity * 2;
        float* new_data = (float*)realloc(buf->data, new_cap * sizeof(float));
        if (!new_data) return false;
        
        buf->data = new_data;
        buf->capacity = new_cap;
    }
    
    buf->data[buf->count++] = sample;
    return true;
}
Why this works & C concepts used: Uses realloc for dynamic heap array expansion. Assigns reallocated memory to a temporary pointer prior to updating the struct to prevent heap pointer loss if allocation fails.

Exercise 9.2 — Polymorphic Tagged Union Runtime Audio Object System
Design a runtime polymorphic audio parameter system using a tagged union. Define an enum ParamType_t (PARAM_INT, PARAM_FLOAT, PARAM_VECTOR) and a struct AudioParam_t storing the tag type and corresponding union payload. Write an accessor function that extracts float values safely while asserting type tag match. 
#include <stdbool.h>
#include <stdint.h>

typedef enum {
    PARAM_INT,
    PARAM_FLOAT,
    PARAM_VECTOR
} ParamType_t;

typedef struct {
    ParamType_t type;
    union {
        int32_t val_int;
        float   val_float;
        struct {
            float* vec_data;
            uint32_t vec_len;
        } val_vec;
    } payload;
} AudioParam_t;

bool get_param_float(const AudioParam_t* param, float* out_val) {
    if (!param || !out_val || param->type != PARAM_FLOAT) {
        return false;
    }
    *out_val = param->payload.val_float;
    return true;
}
Why this works & C concepts used: Combines enums and unions to implement safe type-tagged runtime objects in pure C. Explicit tag checking prevents invalid union payload interpretation.

Subject 10: Automatic Memory Management & Custom Garbage Collector Design

Medium
Exercise 10.1 — Reference-Counting Memory Tracker for Shared Audio Buffers
Implement a reference-counted audio buffer container: RefBuffer_t containing float* data, uint32_t ref_count, and size_t size. Write functions RefBuffer_t* ref_buf_retain(RefBuffer_t* buf) and void ref_buf_release(RefBuffer_t* buf) that increment and decrement counts, freeing heap resources when ref_count hits zero. 
#include <stdlib.h>
#include <stdint.h>

typedef struct {
    float* data;
    size_t size;
    uint32_t ref_count;
} RefBuffer_t;

RefBuffer_t* ref_buf_retain(RefBuffer_t* buf) {
    if (buf) {
        buf->ref_count++;
    }
    return buf;
}

void ref_buf_release(RefBuffer_t* buf) {
    if (!buf) return;
    if (--buf->ref_count == 0) {
        free(buf->data);
        free(buf);
    }
}
Why this works & C concepts used: Implements deterministic reference counting memory management. Ensures shared heap buffers are automatically freed as soon as the active consumer count drops to zero.

Exercise 10.2 — Two-Phase Mark-and-Sweep Garbage Collector VM State Machine
Construct a mini Garbage Collector VM for dynamic audio graph nodes. Define GcObject_t with a bool is_marked flag and pointer links. Write a function void gc_sweep(GcObject_t** head_ref) that traverses the heap allocation list, unlinking and freeing all unreferenced nodes (is_marked == false) while resetting remaining flags for the next collection cycle. 
#include <stdlib.h>
#include <stdbool.h>

typedef struct GcObject {
    bool is_marked;
    struct GcObject* next;
    float audio_payload[64];
} GcObject_t;

void gc_sweep(GcObject_t** head_ref) {
    if (!head_ref || !*head_ref) return;
    
    GcObject_t** current = head_ref;
    while (*current != NULL) {
        GcObject_t* entry = *current;
        if (!entry->is_marked) {
            /* Unlink unreachable node */
            *current = entry->next;
            free(entry);
        } else {
            /* Reset mark flag for next collection cycle */
            entry->is_marked = false;
            current = &entry->next;
        }
    }
}
Why this works & C concepts used: Implements the sweep phase of a classic Mark-and-Sweep garbage collector using double pointer list traversal (GcObject_t** current) to smoothly unlink dead nodes from the virtual machine heap linked-list without breakages.
