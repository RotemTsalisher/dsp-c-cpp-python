Recommended use

Do not read these linearly like a textbook. Use a loop:

  1. Read the teaching section.
  2. Close the explanation.
  3. Solve every exercise.
  4. Explain the answer aloud in English.
  5. Explain it again in Hebrew.
  6. Write/compile the coding problems.
  7. Benchmark where appropriate.
  8. Only then reveal the solution.

Hard-mode rule

Whenever a solution says “it depends,” you must name what it depends on, how you would measure it, and what decision you would make under the stated constraints.
