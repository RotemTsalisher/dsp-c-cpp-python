Fixed-point: go beyond Q-format vocabulary

Fixed-point is not simply “integers instead of floats.” You are designing a numerical system: range, resolution, intermediate widths, scaling, rounding, saturation, and error propagation all matter. Quantization error model

For a uniform quantizer with step Δ, an idealized error model often treats quantization error as approximately bounded by ±Δ/2 under suitable assumptions. This is a model—not a universal guarantee for every signal or correlated quantization process.

Exercise 11.1

An ADC output is 12-bit unsigned. What is the maximum integer code? If mapped linearly to [0,1], what is the step size?

Maximum code = 2¹²−1 = 4095. If endpoints map to 0 and 1, the step between adjacent codes is 1/4095 ≈ 0.0002442. If a system instead defines 4096 equal bins over a half-open interval, the scaling convention differs—always state the mapping.

Exercise 11.2

A Q1.15 value is shifted left by 3. What risks should you check?

Left shifting increases magnitude and can overflow the integer representation. Check worst-case input range, intermediate width, whether saturation is required, and whether the scaling convention still represents the intended physical value.

Exercise 11.3

A pipeline has gains 2, 0.5, 4, and 0.25. The net gain is what? Why does that not mean intermediate fixed-point scaling is trivial?

Net gain = 2×0.5×4×0.25 = 1. But intermediate stages can reach 2×, then 1×, then 4×, etc. Even if the final gain is unity, intermediate values can overflow. Scaling must account for intermediate dynamic range.

Exercise 11.4

You have 16-bit input and 16-bit coefficient. How do you reason about the product width before choosing an accumulator?

A signed 16×16 multiplication can require up to 32 bits to represent the exact product. Then summing N products can require additional headroom roughly related to log₂(N), depending on bounds. You should derive worst-case magnitude from actual ranges rather than blindly adding a fixed number of bits.

Exercise 11.5

Why is rounding preferable to simple truncation in many fixed-point conversions?

Truncation introduces a systematic quantization bias depending on the sign/scaling convention. Proper rounding can reduce average quantization error, although the exact best policy depends on the application and whether deterministic bias, noise shaping, saturation behavior, or hardware cost matters.

Exercise 11.6

Design a Q-format for a signal known to lie in [-3.0, 3.0]. You have signed 16 bits. Explain your trade-off.

You need enough integer range for ±3 plus margin, while maximizing fractional bits for precision. One approach is to reserve enough integer/sign bits so the representable maximum exceeds 3, then use the remaining bits for fraction. The exact Q notation depends on convention; state it explicitly. Include headroom if real signals can exceed the nominal range.

Exercise 11.7

A fixed-point filter becomes unstable after coefficient quantization, while the floating-point version is stable. Give possible causes.
  • Coefficient quantization moved poles closer to/outside the unit circle.
  • State-variable quantization created nonlinear effects.
  • Overflow/wraparound occurred in the feedback path.
  • Scaling/rounding changed the effective coefficients.
  • Implementation ordering differs from the floating reference.
