Trego Embedded Roadmap: Junior to Expert

Prepare for Trego's "Hacker/Maker" culture by mastering these five levels of Embedded C/C++ development.

Workbook 1: The Tinkerer Basics

Ex 1.1: Bitwise Toggle. Write a macro TOGGLE_BIT(reg, bit) that flips a specific bit in an 8-bit register without affecting others.
Ex 1.2: Byte Swapping. You received a 16-bit sensor value in Little Endian but your system is Big Endian. Write a function to swap the bytes.
Ex 1.3: Frequency Check. Write a function that returns true if a given uint32_t frequency is within the human audible range (20Hz - 20kHz).
Ex 1.4: LED Sequence. Create a loop that generates a binary counter pattern for 4 LEDs (0 to 15).

Ex 2.3: Debouncing. A button is noisy. Write a pseudo-function that only registers a "press" if the signal is stable for 50ms.
Ex 2.4: Circular Buffer. Implement a 4-element integer array that overwrites the oldest data when a 5th element is added (useful for sensor averaging).

Ex 4.3: Watchdog Timer. Write a function to "kick the dog" and explain what happens if your main loop hangs.
Ex 4.4: Task Priorities. If Task A (High) and Task B (Low) share a CPU, how do you ensure Task B doesn't starve?
