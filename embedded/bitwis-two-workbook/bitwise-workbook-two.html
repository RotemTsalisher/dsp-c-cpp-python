Workbook 7: Bitwise Essentials (The "Must-Knows")

The Cheat Sheet

  • SET: REG |= (1 << BIT) (Force a bit to 1)
  • CLEAR: REG &= ~(1 << BIT) (Force a bit to 0)
  • TOGGLE: REG ^= (1 << BIT) (Flip the bit)
  • CHECK: if (REG & (1 << BIT)) (Is bit 1?)

Coding Exercises

Ex 7.1: Multi-Bit Masking (C)

You have an 8-bit variable data. You need to extract bits [2, 3, 4] and shift them to the right so they represent a number from 0-7. (Example: 0b10110100 -> extract 101 -> result 5).

uint8_t result = (data & 0x1C) >> 2;
// 0x1C is binary 00011100

Ex 7.3: The "In-Place" Swap

Swap two integers a and b without using a temporary third variable.

a ^= b;
b ^= a;
a ^= b;
Ex 7.4: Counting Set Bits (The Hacker Way)

Write a function that counts how many bits are set to '1' in a byte. This is called the "Hamming Weight".

int count = 0;
while (n) {
  n &= (n - 1); // Clears the least significant bit set
  count++;
}
