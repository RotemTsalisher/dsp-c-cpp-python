Appendix A - Computational Complexity and the Schür Algorithm

Why Levinson-Durbin is O(p²)

The Levinson-Durbin recursion computes the LPC coefficients incrementally. Rather than solving a full system of equations at once, it builds the solution in stages.

If the LPC order is:

p = LPC order

then the algorithm executes:

m = 1, 2, 3, ..., p

where each stage computes one additional predictor coefficient.

Cost of the Prediction Error Term (Δ)

At stage m, the prediction error term is:

Δ = r[m] + a[1]r[m−1] + a[2]r[m−2] + ... + a[m−1]r[1]

This requires roughly:

m − 1

multiply-accumulate operations. Therefore:

Cost(Δ) = O(m)

Cost of the Coefficient Update

Once the reflection coefficient K is computed, the predictor coefficients must be updated:

a'(k) = a(k) + K · a(m−k)

for:

k = 1 ... m − 1

Again, approximately m−1 operations are required. Therefore:

Cost(update) = O(m)

Cost of a Single Levinson-Durbin Stage

Each stage must perform:

  • Prediction error computation: O(m)
  • Coefficient update: O(m)

Therefore:

Cost(stage m) = O(m)

Total Cost of the Algorithm

The total work is the sum of all stages:

O(1) + O(2) + O(3) + ... + O(p)

which is equivalent to:

1 + 2 + 3 + ... + p

Using the well-known identity:

1 + 2 + ... + p = p(p + 1)/2

and keeping only the dominant term:

p(p + 1)/2 ≈ p²/2

Therefore:

Levinson-Durbin Complexity = O(p²)

The Toeplitz Structure

The LPC normal equations can be written as:

R · a = b

where R is the autocorrelation matrix.

Because the matrix is Toeplitz, every diagonal contains identical values:

[r₀ r₁ r₂ r₃] [r₁ r₀ r₁ r₂] [r₂ r₁ r₀ r₁] [r₃ r₂ r₁ r₀]

Only the autocorrelation sequence is needed to describe the entire matrix.

What Happens with a Generic Matrix Solver?

Suppose the Toeplitz structure is ignored and the system is treated as a completely arbitrary dense matrix.

Standard techniques such as:

  • Gaussian Elimination
  • LU Decomposition
  • Explicit Matrix Inversion

have computational cost approximately proportional to:

O(N³)

where N is the matrix dimension.

For LPC:

N = p

thus:

Dense Matrix Solution = O(p³)

Levinson-Durbin is therefore significantly more efficient because it exploits the Toeplitz structure directly.

Why Toeplitz Structure Reduces Complexity

A generic p × p matrix contains:

p²

independent values.

A Toeplitz matrix contains only:

2p − 1

independent values.

Example:

[a b c d] [b a b c] [c b a b] [d c b a]

The entire matrix is determined solely by:

a, b, c, d

This redundancy is the property exploited by Levinson-Durbin and related algorithms.

The Schür Algorithm

The Schür algorithm is another recursive method for solving Toeplitz systems and estimating reflection coefficients.

Like Levinson-Durbin, it:

  • Uses the Toeplitz structure directly
  • Avoids explicit matrix inversion
  • Produces reflection coefficients
  • Avoids generic O(p³) solvers

Conceptually, both algorithms compute the same physical quantities:

K₁, K₂, K₃, ..., Kp

but they organize the recursion differently.

For most LPC derivations, Levinson-Durbin is the standard presentation. The Schür recursion is valuable to know because it provides an alternative Toeplitz-based solution and is often preferred in certain hardware-oriented and parallel implementations.

Summary

Stage m → O(m)

Total work: O(1)+O(2)+...+O(p) = O(p²)

Dense matrix solve: O(p³)

Levinson-Durbin exploits Toeplitz structure and therefore reduces the computational complexity from O(p³) to O(p²).
