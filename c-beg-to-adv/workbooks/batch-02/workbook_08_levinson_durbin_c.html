A. What problem are we solving?

Linear prediction asks: can I predict the next sample from a few past samples?

x̂[n] = − Σk=1..p a(k) · x[n−k]

The coefficients a(1)..a(p) are chosen to minimize the mean-square prediction error. That leads to the normal equations (Yule–Walker for the AR / autocorrelation method).

Levinson–Durbin is an efficient solver for those normal equations when the matrix is Toeplitz — not a new estimator by itself.

עברית

חיזוי ליניארי: מנחשים את הדגימה הבאה משילוב של כמה דגימות קודמות. המקדמים נבחרים כדי למזער את שגיאת החיזוי בממוצע ריבועי — וזה מוביל למשוואות נורמליות. Levinson–Durbin הוא פותר יעיל למשוואות האלה כשהמטריצה היא Toeplitz.

B. Autocorrelation γ_xx(k)

For a wide-sense-stationary signal, the autocorrelation depends only on the lag k:

γ_xx(k) = E[ x[n] · x*[n−k] ]

In practice (finite real block of length N), a common biased estimate is:

r[k] ≈ (1/N) · Σn=k..N−1 x[n] · x[n−k] for k = 0..p

We need r[0], r[1], …, r[p] as input to Levinson–Durbin. For real signals, r[−k] = r[k].

עברית

אוטוקורלציה תלויה רק בהפרש הזמן (lag). בפועל מעריכים אותה מסדרת דגימות סופית. ל־Levinson–Durbin צריך את הווקטור r[0]…r[p]. באות אמיתי: r[−k]=r[k].

C. The Toeplitz autocorrelation matrix Γ

The normal equations pack lags into a matrix that is Toeplitz (constant along diagonals) and, for complex data, Hermitian. For real data it is symmetric Toeplitz:

Γ_p = [ r[0] r[1] r[2] … r[p−1] ] [ r[1] r[0] r[1] … r[p−2] ] [ r[2] r[1] r[0] … r[p−3] ] [ … … … … … ] [ r[p−1] r[p−2] … … r[0] ]

Only the first row (or first column) needs storage — O(p) numbers define an p×p matrix.

עברית

מטריצת האוטוקורלציה היא Toeplitz (אלכסונים קבועים). באות אמיתי היא גם סימטרית. מספיק לשמור את שורת הלגים — זה הסוד שמאפשר אלגוריתם O(p²) במקום היפוך כללי O(p³).

D. Normal equations (what we solve)

Γ_p · a = −γ where a = [a(1), a(2), …, a(p)]ᵀ γ = [r[1], r[2], …, r[p]]ᵀ

Naive solve: Gaussian elimination / Cholesky on dense Γ → about O(p³).

Levinson–Durbin exploits Toeplitz structure → about O(p²) and also produces reflection coefficients K_m and forward prediction-error energies E_m for free.

עברית

פותרים Γ·a = −γ. פתרון כללי יקר; Levinson–Durbin מנצל את המבנה ומחזיר גם מקדמי השתקפות ואנרגיות שגיאה.

E. Order-1 and order-2 by hand (intuition)

Order 1:

a₁(1) = K₁ = − r[1] / r[0] E₁ = r[0] · (1 − |K₁|²) = r[0] + a₁(1)·r[1] (real case)

Order 2 (real), building on order 1:

K₂ = a₂(2) = − ( r[2] + a₁(1)·r[1] ) / E₁ a₂(1) = a₁(1) + K₂ · a₁(1) E₂ = E₁ · (1 − K₂²)

Notice the pattern: each new order adds one reflection coefficient and updates older a’s.

עברית

סדר 1: מקדם יחיד K₁=−r[1]/r[0]. סדר 2 משתמש ב־E₁ כדי לחשב K₂ ומעדכן את a(1). כל עליית סדר = מקדם השתקפות חדש + עדכון המקדמים הישנים.

F. The full Levinson–Durbin recursion (real signals)

Initialize: E = r[0]. For m = 1 .. p:

Δ = r[m] + Σk=1..m−1 a[k] · r[m−k] // “forward residual correlation” K = − Δ / E // reflection coeff = a_m(m) for k = 1 .. m−1: a_new[k] = a[k] + K · a[m−k] // use OLD a on the right a[m] = K E = E · (1 − K·K) // must keep |K| < 1 for E > 0

Indexing note: many texts use 1-based a(1)..a(p). In C arrays we often store a[0] unused or shift to a[0]=a(1). Be consistent.

In-place trap: when updating a[k], you need the old a[m−k]. Use a temporary buffer (or walk only half the indices carefully).

עברית

בכל שלב m: מחשבים Δ, אחר כך K=−Δ/E, מעדכנים את המקדמים עם הערכים הישנים, שומרים a[m]=K, ומעדכנים E. מלכודת: בעדכון במקום חייבים לא לדרוס ערך שעדיין נחוץ לצד השני של הנוסחה.

G. What Levinson–Durbin is / is not (critical for LLNR readers)

It isIt is not
An O(p²) solver for Toeplitz normal equations of linear prediction Automatically “Wiener–Hopf → FIR taps from a mask”
A factory for reflection coeffs K_m and AR / all-pole predictor coeffs A substitute for cepstral min-phase FIR design
Stable all-pole if |K_m| ≤ 1 for all m (real case: < 1 strictly for E>0) A guarantee that a truncated FIR of the AR impulse response matches a spectral mask

Same Toeplitz discipline appears when solving Wiener–Hopf R h = p for FIR — but the right-hand side and meaning of the taps differ. Keep the names straight.

עברית

Levinson–Durbin = פותר למשוואות חיזוי / LPC (לרוב מוביל ל־all-pole). Wiener–Hopf ל־FIR מהמסכה הוא סיפור קשור מבחינת Toeplitz, אבל לא אותו פלט ולא אותה מטרה.

Foundation · Ex 1
What is linear prediction?

Theory

A p-th order linear predictor forms x̂[n] from the previous p samples with weights −a(k). The prediction error is e[n] = x[n] − x̂[n] = x[n] + Σ a(k) x[n−k]. Minimizing E[e²] gives the normal equations.

עברית

חזאי מסדר p בונה ניחוש לדגימה הנוכחית משילוב של p דגימות קודמות. שגיאת החיזוי היא ההפרש; מזעור הריבוע הממוצע נותן את המשוואות הנורמליות.

Foundation · Ex 2
Estimate autocorrelation from a short block

Theory

Biased ACF for real x[0..N−1]: r[k] = (1/N) Σ_{n=k}^{N−1} x[n] x[n−k]. r[0] is (average) energy. You need r[0..p] for order-p Levinson–Durbin.

עברית — כתב יד

חשב r[0], r[1] ל־x={1,1,1,1}. למה r[1] קטן יותר?

Coding (C)

  • Implement void acf_biased(const double *x, int N, double *r, int p); filling r[0..p].
  • Test on {1,1,1,1}, p=2; print r.
r[0]=(1+1+1+1)/4=1. r[1]=(1·1+1·1+1·1)/4=0.75. Fewer products and same samples → smaller lag-1 sum.
r[0]=1, r[1]=0.75. יש פחות איברים ב־lag 1.
#include <stdio.h>

void acf_biased(const double *x, int N, double *r, int p)
{
    int k, n;
    for (k = 0; k <= p; ++k) {
        double s = 0.0;
        for (n = k; n < N; ++n)
            s += x[n] * x[n - k];
        r[k] = s / (double)N;
    }
}

int main(void)
{
    double x[4] = {1,1,1,1};
    double r[3];
    acf_biased(x, 4, r, 2);
    printf("r0=%.6f r1=%.6f r2=%.6f\n", r[0], r[1], r[2]);
    return 0;
}
Foundation · Ex 3
Build a Toeplitz Γ from the lag vector

Theory

Given r[0..p−1], the p×p matrix has Γ[i][j] = r[|i−j|] (real case). You should be able to write Γ without storing a full 2D table in production — but building it once aids learning.

Coding (C)

  • Write void toeplitz_from_r(const double *r, int p, double *G); where G is row-major p*p.
  • Print Γ for r={4,2,1}, p=3.
[ 4 2 1 ]
[ 2 4 2 ]
[ 1 2 4 ]
אלכסון ראשי 4; אלכסון ראשון 2; פינות 1.
#include <stdio.h>

void toeplitz_from_r(const double *r, int p, double *G)
{
    int i, j;
    for (i = 0; i < p; ++i)
        for (j = 0; j < p; ++j) {
            int d = i - j;
            if (d < 0) d = -d;
            G[i * p + j] = r[d];
        }
}

int main(void)
{
    double r[3] = {4,2,1};
    double G[9];
    int i, j;
    toeplitz_from_r(r, 3, G);
    for (i = 0; i < 3; ++i) {
        for (j = 0; j < 3; ++j) printf("%g ", G[i*3+j]);
        putchar('\n');
    }
    return 0;
}
Building · Ex 4
Order-1 normal equation by hand

Theory

For p=1: Γ = [r[0]], γ = [r[1]], so r[0]·a(1) = −r[1] ⇒ a(1)=−r[1]/r[0]=K₁. Then E₁ = r[0](1−K₁²).

עברית

בסדר 1 המשוואה היא סקלרית. K₁=a(1). האנרגיה E₁=r[0](1−K₁²).

Handwriting

  1. r[0]=1, r[1]=0.5. Find K₁ and E₁.
  2. If |r[1]| > r[0], what goes wrong conceptually?

עברית — כתב יד

עם r0=1, r1=0.5 מצא K₁ ו־E₁. מה אם |r1|>r0?

Coding (C)

  • Function int ld_order1(double r0, double r1, double *k, double *E); return −1 if r0<=0 or |k|>=1.
K₁=−0.5, E₁=1·(1−0.25)=0.75. If |r1|>r0, |K|>1 and E becomes negative — invalid ACF / non-positive-definite Γ.
K=−0.5, E=0.75. |K|>1 אומר שמטריצה לא חוקית/לא PD.
#include <stdio.h>
#include <math.h>

int ld_order1(double r0, double r1, double *k, double *E)
{
    if (r0 <= 0.0) return -1;
    *k = -r1 / r0;
    if (fabs(*k) >= 1.0) return -1;
    *E = r0 * (1.0 - (*k) * (*k));
    return 0;
}

int main(void)
{
    double k, E;
    if (ld_order1(1.0, 0.5, &k, &E) == 0)
        printf("K=%.6f E=%.6f\n", k, E);
    return 0;
}
Building · Ex 5
Order-2 step from the textbook formulas

Theory

Real order-2 update (Proakis-style): K₂ = −(r[2]+a₁(1)r[1])/E₁, a₂(1)=a₁(1)+K₂ a₁(1), a₂(2)=K₂, E₂=E₁(1−K₂²).

עברית

מעדכנים מסדר 1 לסדר 2 עם הנוסחאות בספר: K₂ מהשארית, ואז a₂(1) ו־E₂.

Handwriting

Start from r[0]=1, r[1]=0.5, r[2]=0.2. You already have K₁=−0.5, E₁=0.75. Compute K₂, a₂(1), a₂(2), E₂.

עברית — כתב יד

חשב את סדר 2 מתוך הנתונים למעלה.

Coding (C)

  • Hardcode the order-1 result, then implement one order-2 update; print coeffs and E.
Δ = r2 + a1*r1 = 0.2 + (−0.5)(0.5) = −0.05. K₂ = −Δ/E₁ = 0.05/0.75 ≈ 0.066667.
a₂(1)=−0.5 + K₂(−0.5)≈−0.53333. a₂(2)=K₂. E₂=0.75(1−K₂²)≈0.74667.
K₂≈0.0667, a(1)≈−0.533, E₂ מעט מתחת ל־E₁.
#include <stdio.h>

int main(void)
{
    double r0=1, r1=0.5, r2=0.2;
    double a1 = -r1/r0;
    double E1 = r0*(1.0 - a1*a1);

Building · Ex 6
Reflection coefficients and the |K|≤1 rule

Theory

At each stage, a_m(m)=K_m. For a valid positive-definite autocorrelation, |K_m|<1 (real case) and the forward error energies are nonincreasing: E₀≥E₁≥…≥E_p≥0. Lattice filters use the K_m directly.

עברית

בכל שלב המקדם האחרון הוא מקדם ההשתקפות. |K|<1 נדרש ליציבות/חיוביות. האנרגיות יורדות מונוטונית.

Handwriting

  1. If some |K_m|=1, what happens to E_m?
  2. Why might a DSP engineer prefer checking |K| over checking roots of A(z)?

עברית — כתב יד

מה קורה ל־E כש־|K|=1? למה לבדוק K נוח יותר משורשי הפולינום?

Coding (C)

  • Given an array of K[1..p], write int check_k(const double *K, int p); returning 0 if all |K|<1−ε.
E_m = E_{m−1}(1−1)=0: perfect prediction / singular. Checking |K| is O(1) per stage and gives a stability test for the all-pole filter without root finding.
|K|=1 מאפס את האנרגיה. בדיקת K זולה ויציבה כמבחן ליציבות all-pole.
#include <stdio.h>
#include <math.h>

int check_k(const double *K, int p)
{
    const double eps = 1e-12;
    int m;
    for (m = 1; m <= p; ++m)
        if (!(fabs(K[m]) < 1.0 - eps))
            return -1;
    return 0;
}

int main(void)
{
    double K[4] = {0, -0.5, 0.1, 0.2}; /* K[0] unused */

    return 0;
}
Intermediate · Ex 7
One recursive stage: Δ, K, update a, update E

Theory

General stage m: Δ = r[m] + Σ_{k=1}^{m−1} a[k] r[m−k], K=−Δ/E, a'[k]=a[k]+K a[m−k], a'[m]=K, E'=E(1−K²). This is the heart of Levinson–Durbin.

עברית

זה לב האלגוריתם: חישוב Δ, K, עדכון a, עדכון E.

Handwriting

Suppose current (order 2) a(1)=−0.533333, a(2)=0.066667, E=0.746667, and r[3]=0.05. Compute Δ and K₃ only (you may round to 6 decimals).

עברית — כתב יד

חשב Δ ו־K₃ בקירוב.

Coding (C)

  • Implement int ld_stage(double *a, double *E, const double *r, int m); updating in-place from order m−1 to m (a[1..m−1] valid on entry).
Δ = r3 + a1 r2 + a2 r1 ≈ 0.05 + (−0.533333)(0.2) + (0.066667)(0.5) ≈ 0.05 − 0.106667 + 0.033333 ≈ −0.023333.
K₃ = −Δ/E ≈ 0.023333/0.746667 ≈ 0.03125.
Δ≈−0.0233, K₃≈0.031.
#include <stdio.h>
#include <math.h>
#include <string.h>

int ld_stage(double *a, double *E, const double *r, int m)
{
    int k;
    double delta = r[m];
    double K, anew[64];
    if (m >= 64) return -1;
    for (k = 1; k <= m - 1; ++k)
        delta += a[k] * r[m - k];
    if (*E <= 0.0) return -1;
    K = -delta / *E;
    if (fabs(K) >= 1.0) return -1;
    for (k = 1; k <= m - 1; ++k)
        anew[k] = a[k] + K * a[m - k];
    for (k = 1; k <= m - 1; ++k)
        a[k] = anew[k];
    a[m] = K;
    *E *= (1.0 - K * K);
    return 0;
}

int main(void)
{
    double r[4] = {1.0, 0.5, 0.2, 0.05};
    double a[4] = {0};
    double E = r[0];
    ld_stage(a, &E, r, 1);
    ld_stage(a, &E, r, 2);
    ld_stage(a, &E, r, 3);
    printf("a1=%.6f a2=%.6f a3=%.6f E=%.6f\n", a[1], a[2], a[3], E);
    return 0;
}

עברית — כתב יד

אילו פלטים כדאי להחזיר במודול DSP אמיתי?

Coding (C)

  • Implement int levinson_durbin(const double *r, int p, double *a, double *E_out);
  • r has length p+1 (r[0..p]). a[1..p] written (a[0] unused).
a[1..p], optionally K[1..p], E_p, and an error code (singular / |K|≥1 / bad r0).
מקדמים, אופציונלית K, אנרגיה סופית, וקוד שגיאה.
#include <stdio.h>
#include <math.h>
#include <string.h>

int levinson_durbin(const double *r, int p, double *a, double *E_out)
{
    int m, k;
    double E, delta, K, anew[256];
    if (p < 1 || p >= 256 || r[0] <= 0.0) return -1;
    memset(a, 0, (size_t)(p + 1) * sizeof(double));
    E = r[0];
    for (m = 1; m <= p; ++m) {
        delta = r[m];
        for (k = 1; k <= m - 1; ++k)
            delta += a[k] * r[m - k];
        K = -delta / E;
        if (fabs(K) >= 1.0) return -2;
        for (k = 1; k <= m - 1; ++k)
            anew[k] = a[k] + K * a[m - k];
        for (k = 1; k <= m - 1; ++k)
            a[k] = anew[k];
        a[m] = K;
        E *= (1.0 - K * K);
    }
    *E_out = E;
    return 0;
}

int main(void)
{
    double r[4] = {1.0, 0.5, 0.2, 0.05};
    double a[4], E;
    int i;

עברית

Handwriting

Write the 2×2 system explicitly for general r0,r1,r2.

עברית — כתב יד

כתוב את מערכת 2×2.

Coding (C)

  • Solve 2×2 by determinants; run LD p=2; print max abs coeff error.
[[r0,r1],[r1,r0]] [a1,a2]ᵀ = −[r1,r2]ᵀ.
זו בדיוק Γ₂ a = −γ.
#include <stdio.h>
#include <math.h>

int main(void)
{
    double r0=1, r1=0.5, r2=0.2;
    /* Solve [[r0,r1],[r1,r0]] [a1,a2]^T = [-r1,-r2]^T */
    double det = r0*r0 - r1*r1;
    double a1 = (-r0*r1 + r1*r2) / det;
    double a2 = (-r0*r2 + r1*r1) / det;

    /* LD */
    double A1 = -r1/r0;
    double E1 = r0*(1-A1*A1);
    double K2 = -(r2 + A1*r1)/E1;
    double L1 = A1 + K2*A1;
    double L2 = K2;

    printf("dense a=(%.12f, %.12f)\n", a1, a2);
    printf("LD    a=(%.12f, %.12f)\n", L1, L2);
    printf("err=%.3e\n", fmax(fabs(a1-L1), fabs(a2-L2)));
    return 0;
}

#include <stdio.h>
#include <math.h>

void acf_biased(const double *x, int N, double *r, int p)
{
    int k, n;
    for (k = 0; k <= p; ++k) {
        double s = 0.0;
        for (n = k; n < N; ++n) s += x[n] * x[n-k];
        r[k] = s / (double)N;
    }
}

int levinson_durbin(const double *r, int p, double *a, double *E_out)
{
    int m, k; double E = r[0], delta, K, anew[32];
    if (r[0] <= 0) return -1;
    for (k = 0; k <= p; ++k) a[k] = 0;
    for (m = 1; m <= p; ++m) {
        delta = r[m];
        for (k = 1; k <= m-1; ++k) delta += a[k]*r[m-k];
        K = -delta / E;
        if (fabs(K) >= 1.0) return -2;
        for (k = 1; k <= m-1; ++k) anew[k] = a[k] + K*a[m-k];
        for (k = 1; k <= m-1; ++k) a[k] = anew[k];
        a[m] = K; E *= (1.0 - K*K);
    }
    *E_out = E; return 0;
}

int main(void)
{
    enum { N = 64, P = 4 };
    double x[N], r[P+1], a[P+1], E;
    double w[8] = {0.1,-0.2,0.05,0.3,-0.1,0.2,-0.05,0.0};
    int n, i;
    x[0] = w[0];
    for (n = 1; n < N; ++n) x[n] = 0.9 * x[n-1] + w[n & 7];
    acf_biased(x, N, r, P);
    levinson_durbin(r, P, a, &E);
    for (i = 1; i <= P; ++i) printf("a%d=%.6f\n", i, a[i]);
    printf("E=%.6f (expect a1 near -0.9)\n", E);
    return 0;
}

#include <math.h>
#include <string.h>

int levinson_durbin(const double *r, int p, double *a, double *E_out)
{

Senior / Hero · Ex 14
Complexity: why O(p²) beats O(p³), and Schür in one paragraph

Theory

Each stage m costs O(m) for the inner product Δ plus O(m) for the a-update → sum_m O(m) = O(p²). Dense inversion ignores Toeplitz → O(p³). The Schür algorithm is a related Toeplitz-positive-definiteness / reflection recursion that avoids some inner products and maps well to parallel hardware — know it exists.

עברית

כל שלב עולה O(m) ולכן סה״כ O(p²). היפוך צפוף O(p³). אלגוריתם Schür קשור ומתאים יותר למקביליות.

#include <stdio.h>
#include <math.h>

long long flops;

int levinson_durbin_counted(const double *r, int p, double *a, double *E_out)
{
    int m, k; double E = r[0], delta, K, anew[256];
    flops = 0;
    for (k = 0; k <= p; ++k) a[k] = 0;
    for (m = 1; m <= p; ++m) {
        delta = r[m];
        for (k = 1; k <= m - 1; ++k) { delta += a[k] * r[m - k]; ++flops; }
        K = -delta / E; ++flops;
        for (k = 1; k <= m - 1; ++k) { anew[k] = a[k] + K * a[m - k]; flops += 2; }
        for (k = 1; k <= m - 1; ++k) a[k] = anew[k];
        a[m] = K;
        E *= (1.0 - K * K); flops += 2;
    }
    *E_out = E; return 0;
}

int main(void)
{

    for (p = 8; p <= 32; p *= 2) {
        levinson_durbin_counted(r, p, a, &E);
        printf("p=%d flops=%lld flops/p^2=%.2f\n", p, flops, flops / (double)(p * p));
    }
    return 0;
