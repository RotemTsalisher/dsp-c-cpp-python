Problem 1 · Warm-up

Prompt: (Verbal + whiteboard) You receive left and right PCM samples as double values in the range [-1.0, 1.0]. The product must output a mono mix for a single-earpiece monitor.

Deliverable:

  • State the formula you would use and why it is appropriate for a quick monitor path.
  • Write a C function double mono_mix(double left, double right) implementing your formula.
  • List one pitfall when the inputs are already near full scale.
double mono_mix(double left, double right)
{
    return 0.5 * (left + right);
}

Discussion: Equal-power-ish monitoring often uses simple averaging ((L+R)/2) because it is cheap and symmetric. Pitfall: if L and R are both hot and in phase, the sum can exceed 1.0 before any headroom processing — a limiter or scaler downstream is required on production paths.

Tests numeric literacy and basic audio domain knowledge using only doubles and arithmetic from the curriculum.
Problem 2 · Input / parsing

Prompt: A teammate wrote firmware that reads a calibration tuple offset counts gain from stdin using a single scanf call. Operators report that multi-word site names break the parser and the gain is sometimes wrong on large values.

Deliverable:

  • Explain what is likely wrong with reading all fields through one scanf pattern when the protocol allows spaces in the site field.
  • Sketch a corrected read order (pseudocode or C) that uses scanf and fgets appropriately for: integer offset, integer counts, floating gain, and a 40-character site string.
  • Do not implement full validation — focus on capture order and newline handling.
int offset = 0;
int counts = 0;
float gain = 0.0f;
char site[40] = {0};

scanf("%d", &offset);
scanf("%d", &counts);
scanf("%f", &gain);
getchar(); /* consume newline before fgets */
fgets(site, sizeof site, stdin);
/* trim trailing '\n' from site */

Discussion: A single format string cannot safely span a free-text token with spaces. Mixed-type reads also leave the input buffer in a state where the next read may skip or mis-align. Reading scalars first, then consuming the line break before fgets, is the standard fix at this course level.

Interviewers probe whether candidates understand stdin buffering — a daily issue in lab tooling.
Problem 3 · Functions + conditionals

Prompt: Classify FFT bins for a simple LED ring: each bin index maps to an energy level that drives color coding on the bench.

Deliverable:

  • Implement const char *band_label(int bin_index) returning "SUB" for 0–1, "BASS" for 2–5, "MID" for 6–9, "HIGH" for 10–15, and "OOB" otherwise.
  • Implement int energy_level(double power, double ref) returning 0–3 based on ratio power/ref (<0.25 → 0, <0.5 → 1, <0.75 → 2, else 3). If ref <= 0, return 0.
  • Write a short main that prints two example lines combining bin index, label, and level.
#include <stdio.h>

char const *band_label(int bin_index)
{
    if (bin_index < 0 || bin_index > 15) {
        return "OOB";
    }
    if (bin_index <= 1) {
        return "SUB";
    }
    if (bin_index <= 5) {
        return "BASS";
    }
    if (bin_index <= 9) {
        return "MID";
    }
    return "HIGH";
}

int energy_level(double power, double ref)
{
    if (ref <= 0.0) {
        return 0;
    }
    double const r = power / ref;
    if (r < 0.25) {
        return 0;
    }
    if (r < 0.50) {
        return 1;
    }
    if (r < 0.75) {
        return 2;
    }
    return 3;
}

int main(void)
{
    printf("bin 3 -> %s level %d\n", band_label(3), energy_level(0.40, 1.0));
    printf("bin 12 -> %s level %d\n", band_label(12), energy_level(0.90, 1.0));
    return 0;
}
Compact function design with chained comparisons — common live-coding pattern.
Problem 4 · Pointers

Prompt: (Live coding) A DMA buffer is exposed as a pointer to the first sample. Update every other sample in place to zero without returning a new array.

Deliverable:

  • Function signature: void zero_even_indices(double *begin, int length).
  • Zero elements at indices 0, 2, 4, … using pointer arithmetic (subscripts optional for the interviewer if you explain your walk).
  • Demonstrate in main on a six-element stack array and print before/after on one line each.
#include <stdio.h>

void zero_even_indices(double *begin, int length)
{
    if (begin == NULL || length <= 0) {
        return;
    }
    for (int i = 0; i < length; i += 2) {
        *(begin + i) = 0.0;
    }
}

static void print_arr(double const *a, int n)
{
    for (int i = 0; i < n; ++i) {
        printf("%.1f ", a[i]);
    }
    putchar('\n');
}

int main(void)
{
    double buf[6] = {1, 2, 3, 4, 5, 6};
    print_arr(buf, 6);
    zero_even_indices(buf, 6);
    print_arr(buf, 6);
    return 0;
}
Tests pointer indexing idioms and in-place mutation — typical firmware follow-up after array questions.
Problem 5 · Files + loops

Prompt: (Design discussion) Production wants a nightly CSV dump of per-frame RMS values. Each line: frame_id,rms\n. The device has no heap; maximum 64 frames per file.

Deliverable:

  • Describe which fopen mode you use for a fresh nightly file and why.
  • Write int append_rms_row(FILE *fp, int frame_id, double rms) that appends one line and returns 0 on success.
  • Write int count_rows(const char *path) that opens for read and counts newline-terminated records using a loop (no need to parse floats).
#include <stdio.h>

int append_rms_row(FILE *fp, int frame_id, double rms)
{
    if (fp == NULL) {
        return 1;
    }
    if (fprintf(fp, "%d,%.6f\n", frame_id, rms) < 0) {
        return 1;
    }
    return 0;
}

int count_rows(char const *path)
{
    FILE *fp = fopen(path, "r");
    if (fp == NULL) {
        return -1;
    }
    int rows = 0;
    char line[128];
    while (fgets(line, (int)sizeof line, fp) != NULL) {
        ++rows;
    }
    fclose(fp);
    return rows;
}

/* Nightly create/truncate: fopen(path, "w") */

Discussion: Mode "w" creates or truncates — appropriate for a new nightly artifact. Append during the shift could use "a" if the file must survive across sessions. Fixed line buffer respects the no-heap constraint.

Separates API knowledge (fopen modes) from looped reading — a frequent system-design mini question.
Problem 6 · Integrated screen

Prompt: (45-minute take-home style) Build a miniature PSD session logger: operator enters how many frames to capture (max 8), enters four bin powers per frame, writes them to session.csv, reads the file back, and prints whether the peak bin index matches between the last entered frame and the last read frame.

Deliverable:

  1. Struct with int frame_id and double bins[4].
  2. Function to find index of maximum bin in one struct.
  3. Write all captured frames to CSV (same format as curriculum workbook: id + four floats).
  4. Read back into a static array; compare peak indices for last written vs last read.
  5. Print PEAK MATCH or PEAK MISMATCH.
#include <stdio.h>

struct Frame {
    int frame_id;
    double bins[4];
};

int peak_bin(struct Frame const *f)
{
    int idx = 0;
    for (int i = 1; i < 4; ++i) {
        if (f->bins[i] > f->bins[idx]) {
            idx = i;
        }
    }
    return idx;
}

int write_session(char const *path, struct Frame const *frames, int n)
{
    FILE *fp = fopen(path, "w");
    if (fp == NULL) {
        return 1;
    }
    for (int i = 0; i < n; ++i) {
        fprintf(fp, "%d,%.6f,%.6f,%.6f,%.6f\n",
                frames[i].frame_id,
                frames[i].bins[0], frames[i].bins[1],
                frames[i].bins[2], frames[i].bins[3]);
    }
    fclose(fp);
    return 0;
}

int read_session(char const *path, struct Frame *frames, int cap, int *out_n)
{
    FILE *fp = fopen(path, "r");
    if (fp == NULL) {
        return 1;
    }
    int n = 0;
    while (n < cap) {
        struct Frame *f = &frames[n];
        if (fscanf(fp, "%d,%lf,%lf,%lf,%lf",
                   &f->frame_id,
                   &f->bins[0], &f->bins[1],
                   &f->bins[2], &f->bins[3]) != 5) {
            break;
        }
        ++n;
    }
    fclose(fp);
    if (out_n) {
        *out_n = n;
    }
    return 0;
}

int main(void)
{
    struct Frame captured[8] = {0};
    int n = 0;

    printf("Frames to capture (1-8): ");
    if (scanf("%d", &n) != 1 || n < 1 || n > 8) {
        return 1;
    }

    for (int i = 0; i < n; ++i) {
        captured[i].frame_id = 1000 + i;
        printf("Frame %d — four bin powers: ", captured[i].frame_id);
        for (int b = 0; b < 4; ++b) {
            scanf("%lf", &captured[i].bins[b]);
        }
    }

    char const *path = "session.csv";
    if (write_session(path, captured, n) != 0) {
        return 1;
    }

    struct Frame loaded[8] = {0};
    int got = 0;
    if (read_session(path, loaded, 8, &got) != 0 || got < 1) {
        return 1;
    }

    int peak_cap = peak_bin(&captured[n - 1]);
    int peak_load = peak_bin(&loaded[got - 1]);
    printf("%s\n", peak_cap == peak_load ? "PEAK MATCH" : "PEAK MISMATCH");
    return 0;
}
